# 構内・車両基地グループと用途領域

広義の停車場を「構内・車両基地グループ → 用途領域 → 停車可能区間」の三段階で扱う。平行線路の編集用TrackGroupとは別の所属であり、同じ線路を距離で区切って異なる領域へ割り当てられる。

## 開く・生成する

`npm run generate:tojo-areas`。既存 `saves/osm-tobu-tojo-depots.json` が必要。設定は `data/maps/tojo-station-areas.yaml`。出力は `saves/osm-tobu-tojo-areas.json` と `saves/osm-tojo-station-areas.report`。元入力と車両試験セーブは変更しない。

開発サーバーの `/?map=tojo-areas` で川越市構内全体を表示する。領域版がある場合は既存 `/?map=tojo-depots` も領域版を優先する。編集パネルと用途の色・番号は初期状態では非表示。最上部の「施設」タブで開き、既存の左パネルにあるグループ選択で他の構内へ移動する。「地図」へ切り替えると色・番号と編集欄を隠す。地図上の専用ボタンや重ね置きパネルは使わない。

現在は9グループ・63領域、全46旅客駅を保持する。川越市の指定構内区間（旅客ホームと旧2番の線路を除く）、他8グループの元施設対象側線と本線接続部の指定範囲に、未所属の残余区間がないことを生成時に検査する。指定範囲外の全本線・全OSMを自動分類したという意味ではない。数値上0.01 m以下の端部は丸め誤差として扱う。

## 川越市の区分

旅客ホームと旧2番の北側線路はグループ外。北側の分岐・接続区間は残余区間の仮分類であり、単一の入換経路として検証していない。

|北側留置線群|留置線群|2|230.3 m|
|北側保守用側線（仮区分）|保守用側線|1|88.8 m|
|駅西側待機線群（仮区分）|留置線群|2|228.6 m|

|旧工場側・西留置線群（仮区分）|留置線群|4|153.1 m|
|旧工場側・作業線群（用途未確認）|検修・作業線群|2|153.5 m|

南側引上げ領域は約196 mを所有するが、分岐支障を除いた停止可能区間は約106 mである。領域の長さをそのまま留置可能長と呼ばない。引上げ線は一時的な入換停止用であり、通常の留置配置は拒否する。分岐・接続通路には停車場を生成しない。

旧工場側などの用途はゲーム上の仮区分で、実際の現役用途・正式番線・検修設備の復元を断定しない。旧工場への有向進入経路は従来から未確認であり、本件は領域の整理と安全な停止区間の分離である。

## 操作

領域一覧を押すと、その領域へ移動・強調表示する。番号と色が地図と一覧で対応する。グループ全体の外周は破線、領域は色面、通路は線状に表示する。表示面は線路区間から生成する包絡であり、土地境界や測量図ではない。

選択領域では名称・用途・所属グループを変更できる。「この領域をさらに分割」で線路群を選び分けるか、単一区間なら始端からの距離で前後を分ける。元区間を過不足なく分けることと、分割先同士が重複しないことを検査する。停車可能区間は再計算し、短い分割先に無理に作らない。旅客ホーム領域の分割・用途変更はこの画面では対象外。

新規グループは選択施設・側線から作れる。グループがない通常マップでも、「施設」タブで空のグループ作成欄を表示する。既存停車場を領域として追加するか、選択側線の未所属部分を用途未確認の領域として追加し、その後用途を指定する。既存領域へ重なる部分は登録しない。

区分中の線路・分岐、関連停車場を従来の個別編集から壊す操作は拒否する。領域から再編するか区分を解除してから編集する。車両が配置・運転中の領域構造変更は拒否する。名称変更は可能。

## 保存と検証

MapState v15へグループ・領域・カウンタを保存する。v14以前は既存停車場を保ち、空の階層を追加して移行する。親・関連停車場の欠落、範囲重複、関連停車範囲の逸脱、非旅客停車範囲の分岐支障を検証する。

`npm run generate:tojo-areas` 成功。全9グループの指定範囲の未所属0、領域間重複0、線路266本・接続点・転てつ器と全46旅客駅の不変を比較確認。全271テストとビルド成功。ビルドには500 kB超の既存一括バンドル警告があるが失敗ではない。

ブラウザーで川越市の全体・個別領域、引上げ線の90 m位置での二分割（9→10領域）、親所属保持と前側の停車区間0、森林公園20領域への切替を確認した。実際の信号連動・ダイヤ運転・全入出庫の実走は今回の対象外である。

## 建設との責任分担

駅・操車場などの部品の新設、拡張、撤去など物理変更は「建設」。駅グループの作成・名称・所属と既存領域の分割・用途指定など管理上の編集は「施設」。グループ名も左パネルから変更できる。既存の駅名変更は施設の右パネルで行う。操車タブの整理は別作業とする。
