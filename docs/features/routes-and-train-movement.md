# 駅間経路と列車移動

## 現在の機能

- 選択ツールで停車順に駅を選び、右側の「選択駅から経路作成」で運行経路を作る
- 線路上の駅中心と接続点を節点とし、線路距離が最短になる経路を探索する
- 端点接続、途中分岐、複数停車地点を持つ駅を扱う
- 運行経路は青い破線で表示する
- 経路、編成ID、速度を指定して列車を配置する
- 列車は始発で5秒停車して発車し、途中駅で5秒停車し、終着で運行完了になる
- 走行中は青、停車中は橙、終着後は灰色の記号で表示する
- 運行経路と列車状態はセーブ対象である

## 操作

1. 選択ツールで始発駅を選ぶ
2. Shift＋クリックで途中駅、終着駅の順に追加する
3. 「選択駅から経路作成」を押す
4. 運行経路、編成ID、速度を指定する
5. 「列車を配置・発車」を押す

## 現在の制限

- 編成IDは既存Fleetモデルへの参照文字列であり、マップUIから編成を編集・検証しない
- 信号、閉塞、他列車との競合、ダイヤ、加減速は扱わない
- 経路は作成時の線路網を保持し、線路・駅の撤去で無効になれば列車とともに削除する
