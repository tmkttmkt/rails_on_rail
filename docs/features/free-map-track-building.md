# Feature: 自由マップ線路敷設

## 現在の機能

- 地図を主領域とし、上部の機能区分、左上の線路工事パネル、右上の選択情報、下部ステータスで操作する
- 灰色の業務ソフト風UIを使い、通常線路は濃灰、建設中は青、選択は赤、吸着は緑で表示する
- 低倍率では線路を一本の地図記号として表示し、中倍率では軌道下地と左右レール、高倍率では枕木も表示する
- 左右レールの間隔には線路仕様が参照する軌間を使用する
- 境界のないワールド座標上をパンできる
- ポインター位置を維持したまま20%から400%までズームできる
- 直線は始点と終点の2点だけを指定して敷設できる
- 曲線は、最初の2点で初期方向を決め、その後は現在方向に接する一定半径の円弧を順番に延長できる
- 後続区間を追加しても、既に確定した曲線区間は変形しない
- 曲線モードは既設線路の端点または途中へ吸着して伸ばせる。直線モードの始点規則は後述する
- 既設線路から伸ばす場合、接続位置の方向を新線の開始接線として維持する
- 敷設中の曲線は既設線路の端点または途中へ、直線は方向と延長軸が一致する端点へ吸着できる
- 曲線を接続する場合、終点側でも接続先線路の接線方向を維持し、最終区間を接線連続な二円弧で構成する
- 既設線路間を曲線接続する場合は、`N/M`で出発側、終点へカーソルを合わせて`,`/`.`で到着側の束内接続対応を左右へ移動し、半径を確認して終点クリックで確定できる
- 1〜8本を指定し、同じ線形に沿う平行線路を一度に敷設できる
- 同時敷設した各線路は、独立した線形・仕様・工学状態・IDを持つ
- 二本以上を同時敷設すると、独立線路を参照する線路群を自動作成する
- Shift＋クリックで複数線路を選択し、束作成、束への追加、束からの除外、束解体を行える
- 束を解体しても個別線路は残り、線路撤去とは別の操作になる
- 複線から新しい複線を伸ばすと、選択した物理線路へ対応する新線を揃える
- 本数が異なる線路群同士は、中央寄せで接続可能な線路を自動対応する
- 本数が異なる線路群から伸ばす場合、始点クリック後にN/Mで接続する連続範囲を左右へ移動できる
- 接続の初期位置は束全体の中央ではなく、クリックした既設線を起点として束の中央側へ新線を並べる
- 直線モードでは既設直線の途中から生やせず先端だけに接続できるが、既設曲線の途中からは接線方向へ生やせる
- 直線の終点は、延長軸と既設線の方向が一致する先端だけへ接続できる
- 工事パネルに現在の接続候補番号と候補総数を表示する
- 新線束の最低一本が既設束と接続すれば分岐でき、対応しない新線は未接続のまま残る
- N/Mの接続候補は`N+M-1`通りとし、一本だけ接続する左右端の配置まで選べる
- 既設線と同じ中心線区間へ新線を重ねる建設は拒否する
- 端点共有と一点での線路交差は許可する
- 接続は独立した接続点として保存し、各線路の始端・終端・途中位置から双方向に辿れる
- 本数の異なる束へ終点接続する場合も、対応する各線路の端を個別に接続位置へ合わせる
- 手動で束を作成・追加した場合は、線路を物理的な左右順へ並べ直す
- 建設拒否時は敷設中の線路を保持し、修正して再試行できる
- 敷設中の最後の点を戻す、全体を取り消す、線路を確定する操作ができる
- 既設線路を選択して撤去できる
- ズーム段階に応じてグリッド間隔が切り替わる
- ワールド座標をメートルとして扱い、曲線の局所半径と最小半径を近似計算する
- 各線の半径とカントを独立して計算・保存する
- 敷設中に、接続先への束内位置補正を適用した実際のプレビュー線形から、カーソル位置の半径、最小半径、推奨カントを表示する
- 軌間と設計速度を指定し、建設時の推奨カントを線路状態へ保存する
- 選択した線路の最小半径、設計速度、カントを確認できる

## 操作

キーボード割当の正本と予約キーは[操作とキーボード割当](../controls.md)を参照する。

- 直線を敷設: 始点と終点をクリックすると自動確定
- 曲線を敷設: 左側の「曲線」を選び、始点、初期方向を決める点、各円弧区間の終点を順番に置いて確定
- 途中から分岐: 新線の始点を既設線路へ近づけ、緑のリングが表示された位置をクリック
- 接続後の直線: 終点が既設線路の方向軸上へ拘束される
- 接続後の曲線: 既設線路と同じ方向に出発し、その先の制御点へ向けて徐々に曲がる
- 既設線路へ接続: 敷設途中で既設線路へ近づけ、緑のリングをクリックすると自動確定
- N本同時敷設: 左側の本数入力または±ボタンで1〜8本を指定してから敷設
- 点を戻す: `Backspace`
- 敷設を取消: `Escape`
- マップを移動: 移動ツール、マウス中ボタン、または右ボタンでドラッグ
- 拡大縮小: マウスホイールまたは上部ボタン
- 線路を撤去: 選択ツールで線路を選び、`Delete`
- 複数選択: 選択ツールで`Shift`を押しながら線路をクリック
- 束を作成: 二本以上の単独線路を選択し、「束を作成」
- 束へ追加: 既存の束に属する線路と単独線路を同時選択し、「束へ追加」
- 束から外す・解体: 対象線路を選択し、選択情報パネルの操作を使用
- N本からM本への接続調整: 既設束へ始点を置いた後、`N`で左、`M`で右の候補へ移動
- 既設線路間の曲線接続対応調整: 始点選択後に`N/M`で出発側、終点へカーソルを合わせて`,`/`.`で到着側の束内対応を移動し、終点クリックで確定

## 制約

- 背景は抽象的なグリッドで、現実の地図ではない
- 通常の曲線区間は円弧だが、円弧間の緩和曲線をまだ持たず、曲率が境界で変化する
- 既設線路への最終接続区間は二円弧で構成するため各円弧は一定半径だが、接続点では曲率が不連続になる
- 線路間隔は現在12 mで固定
- 推奨カントの式、160 mmの上限、全区間一定のカント分布は暫定値
- 個別線路は用途や運行方向をまだ持たない
- 既設線路側の逆接続情報と分岐器形状はまだ生成しない
- 個別線路同士の端部接続は持つが、分岐器形状を持たない
- 始点・終点の接続は座標と接線を一致させる段階で、既設線路のデータ分割は行わない
- 線路群内の左右順序を手動変更するUIは未実装
- 三線軌条やガントレット軌道など、意図的にレールを共有する設備は未実装
