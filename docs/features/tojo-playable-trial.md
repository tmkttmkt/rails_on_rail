# 東上線の近似再現・短編成試験

実用的なゲームの完成に向け、既存OSMマップから試験用の経路と編成を別セーブへ生成する。元の線路・駅・分岐は変更しない。

地図上部の専用タイトルと駅移動欄は「検証用UI」ラベル・淡い背景・破線枠で表示する。通常のゲーム操作部分とはこの補助部分だけを区別する。

`npm run generate:tojo-trial` を実行し、開発サーバーの `/?map=tojo-trial` で開く。入力は `saves/osm-tobu-tojo-areas.json`、出力は `saves/osm-tojo-playable-trial.json`。設定は[駅順・編成テンプレート](../../data/maps/tojo-trial.yaml)、生成処理は[スクリプト](../../scripts/generate-tojo-playable-trial.ts)に分離する。ODPT時刻表やトークンは使わない。

- 池袋〜小川町33駅、上下2経路・64区間を作成する。停車点・進行方向を連続させた有向経路候補も検査する。実番線の復元や上下の線路分離を確定した結果ではない。
- 既存の試験用双方向気動車2両（全長20m）を取得し、池袋へ初期配置する。実在する東武車両の再現ではない。33駅すべての選択可能範囲に長さが収まることを検査する。
- 留置コマンドによる配置も全範囲で試行し、分岐・近接線による拒否を `saves/osm-tojo-playable-trial.report` へ残す。範囲長への適合と留置可能判定は別である。一部の駅は全候補が留置拒否となる。判定は無効化していない。
- 時計は停止。営業運行・全日ダイヤ・進路競合制御はまだ設定しない。経路・編成配置の保存再開と元データ不変を検査する。

経路作成では指定線路・停車点・距離を使う。不正な停車点を別ホームへ自動置換しない。駅IDのみの既存経路探索は維持する。経路探索の端点指定の回帰は[テスト](../../tests/routeEndpoints.test.ts)を参照する。

2026-11-11: 営業経路も入換と共通の有向探索を使うように修正した。各駅間で進行方向を保持し、分岐で暗黙に反転する経路を拒否する。生成する上下64区間は保存区間列と有向探索の一致も検査する。旧試験セーブは再生成済み。別セーブの旧経路は再作成が必要。[修正Task](../tasks/2026-11-11_fix-directional-operation-routing.md)。
