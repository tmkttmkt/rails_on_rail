# 駅と停車地点

## 現在の機能

- 駅は線路から独立した施設として存在する
- 駅ツールで線路上の一端と反対側の端を順にクリックし、専用ダイアログへ駅名を入力して設置する
- 駅ツールの「一本のみ／束すべて」で対象を切り替える。初期値は「束すべて」で、束に属する線路なら全線路へ停車地点を一括作成する
- 停車地点は線路ID、開始・終了距離、両端座標、両方向停車を保持する
- 駅長は開始・終了距離の差として求め、メートル数を直接入力しない
- 最初の端を指定した後、カーソルまでの駅範囲を緑の破線でプレビューする
- 地図上では確定した駅範囲を線路沿いに帯で表示する
- 既存駅を選択して「駅を延長」を押し、同じ線路上の新しい端をクリックすると範囲を拡張できる。束駅では束内の停車地点をまとめて延長する
- 駅記号と駅名を地図へ表示する
- 選択ツールでは駅記号だけでなく、線路上の駅範囲をクリックしても駅を選択できる。駅範囲では背後の線路より駅を優先する
- Shift＋クリックで複数駅を選び、「駅を統合」で最初に選択した駅へ停車地点をまとめられる。同じ線路上の停車範囲は両駅の外端まで統合する
- 停車地点の線路が撤去され、停車地点がなくなった駅は自動削除する
- 駅と停車地点はセーブ対象である

## 操作

1. 左側の「駅を設置」を選ぶ
2. 必要なら「一本のみ／束すべて」を切り替える
3. 緑の吸着表示が出た線路上で駅の一端をクリックする
4. 同じ線路上で反対側の端をクリックする
5. 駅名を入力する
6. 「設備を選択」で駅記号をクリックすると、右側から改名・延長・撤去できる
7. 複数駅を統合するときはShift＋クリックで追加選択し、「駅を統合」を押す
