# ホーム画面

通常の `/` 起動はホームを表示する。

- 新規ゲーム: 空の自由マップを建設モードで開始する。進行中のマップがある場合は未保存変更の破棄を確認する。既存セーブは消さない。
- 続きから: 同じタブ内の進行中マップへ戻る。起動直後はブラウザー内の最終更新が新しいセーブを読む。どちらもない場合は無効。サーバーのみのセーブはロードから選ぶ。
- ロード: 既存セーブ管理を開き、ブラウザー／サーバーの保存を選んで読む。ホームでは新規保存・上書き・保存名入力を隠す。
- ファイルから読み込む: 既存JSON取込を利用する。取込成功後は地図へ進む。
- ゲーム上部の「ホーム」: マップと未保存変更をメモリに保持して戻る。ブラウザーの再読込・終了を越えて保持する自動保存ではない。

ホーム中はフレームでシミュレーションを進めず、ゲーム用キー入力を処理しない。戻ると元の進行／停止状態を引き継ぎ、経過実時間分の追いつき計算はしない。

`?map=tojo-depots`、`tojo-import`、`siding-trial`、`tojo-areas` の専用入口はホームを省略する。設定・シナリオ選択・新しいゲームルールは今回追加しない。
