# Feature: マップの保存と読込

## 現在の機能

- 上部の「セーブ管理」から複数の名前付きセーブを作成できる。
- セーブ一覧には名前と最終更新日時を表示する。
- 選択したセーブを上書き、読込、名前変更、削除、JSON書出できる。
- 「取込」でJSONファイルを名前付きスロットへ追加し、そのマップを読み込める。
- JSONファイルはセーブ名、作成日時、更新日時、ゲーム状態を持つ。
- 旧形式の生の`MapState` JSONを取り込める。
- 旧ブラウザ内クイックセーブは「旧クイックセーブ」という名前で自動移行する。
- JSON構文、形式version、座標、線路、軌道構成、工学状態、接続を読込前に検証する。
- 読込に失敗した場合は現在のマップを変更しない。
- 読込成功時は敷設途中、選択、吸着など一時的なUI状態を解除する。
- 新規保存、上書き、JSON取込時は、ブラウザ内へ保存した後で同じセーブJSONを開発サーバーへ同期する。
- サーバー同期に失敗してもブラウザ内の保存は維持し、同期だけが失敗したことを表示する。
- 通常プレイ中とローカルセーブ読込時にはサーバーへアクセスしない。上部のセーブボタンで管理画面を開いたときだけ、AIが作成・更新したサーバーセーブを取得して一覧へ表示する。
- サーバーから取得したJSONは`parseSaveFile`で検証し、不正なセーブは一覧へ追加せず現在のマップも変更しない。
- サーバー同期済みスロットはサーバーIDとrevisionをブラウザ内に保持する。サーバー側が先に更新されていた場合は上書きを拒否する。

## 保存対象

- 完成済み線路の形状、複線本数、個別線路と接続
- 接続点の座標と、各線路上の始端・終端・途中位置
- 駅と線路上の停車地点
- 独立線路を束ねる線路群と、その表示名・線路順序
- 軌間、レール、軌道支持方式、路盤
- 設計速度、建設時最小半径、カント
- 次に発行する線路ID

カメラ位置、選択、カーソル、敷設途中の線路は保存しない。

## 制約

- 自動保存とクラウド保存は未実装
- セーブ一覧の並べ替え、検索、サムネイルは未実装
- JSONを任意APIへ試し送りするUIは未実装
- ゲーム状態version 1・2は接続点を持つ形式へ、version 3は駅なしの形式へ、version 4・5の中心位置と駅長は開始・終了境界へ変換し、version 6には空の運行状態を補う
- 次回発行IDが既存ID以下となる壊れた保存データは拒否する
- セーブファイル形式は版番号`1`、ゲーム状態は版番号`8`
- version 7以前のセーブにはゲーム内時計を補ってversion 8へ移行する
