# Research: 鉄道規格カテゴリ

## 目的

Phase 1以降で鉄道規格を導入する際に必要な分類と代表値を整理し、データ定義の土台とする。

## 対象規格

### 軌間（Track Gauge）

軌間は車輪が接するレール内側の幅。軌間が異なる車両は原則として相互乗り入れできない。

| 軌間 | 通称 | 代表例 |
|---|---|---|
| 762mm | 軽便軌間 | 黒部峡谷鉄道、大井川鐵道一部 |
| 1067mm | 狭軌（ケープ軌間） | JR在来線大半、多くの私鉄 |
| 1372mm | 馬車軌間 | 東京都電、京王電鉄一部 |
| 1435mm | 標準軌 | 新幹線、近畿日本鉄道、阪急、京阪 |

ゲームでは軌間をIDではなくmmの数値として保持し、互換性チェックを数値比較で行う。

### 電化方式（Electrification）

集電方式と電圧・周波数の組み合わせ。電化方式が異なる路線への直通には専用車両または変換設備が必要。

| 方式 | 電圧 | 周波数 | 代表例 |
|---|---|---|---|
| 非電化 | — | — | 北海道・四国のローカル線 |
| 直流600V | DC 600V | — | 路面電車・軽便鉄道 |
| 直流750V | DC 750V | — | 一部の都市交通 |
| 直流1500V | DC 1500V | — | JR東日本関東、東急、小田急ほか多数 |
| 交流20kV 50Hz | AC 20kV | 50Hz | 東北・上越新幹線 |
| 交流25kV 50Hz | AC 25kV | 50Hz | 北陸・北海道新幹線、JR東日本一部在来線 |
| 交流25kV 60Hz | AC 25kV | 60Hz | 東海道・山陽・九州新幹線、JR西日本一部在来線 |

直流と交流の境界地点（デッドセクション）を走行するには特殊な制御が必要。

### レール（Rail Weight）

レールはkg/mで表す重量が上位仕様となる。重いレールは耐荷重・速度・軸重に有利だが敷設コストが高い。

| 規格 | 用途 |
|---|---|
| 22〜30kg/m | 軽便・側線・引込線 |
| 37kg/m | ローカル線・旧規格幹線 |
| 40kg/m | 中規格本線（旧型） |
| 50kg/m | 標準的な幹線 |
| 60kg/m | 高速線・重量貨物線 |

### 軸重（Axle Load）

車輪1軸あたりがレールに加える重量。路線ごとに許容軸重が設定され、超過する車両は入線不可。

| 分類 | 軸重目安 | 代表用途 |
|---|---|---|
| 軽量 | 〜8t | 路面電車・軽便鉄道 |
| 標準 | 14〜16t | 一般旅客車 |
| 重量 | 18〜25t | 貨物列車 |

### 保安装置（Safety System）

自動列車停止・制御装置。路線側と車両側の両方に対応装置が必要。

| 規格 | 概要 |
|---|---|
| なし（目視） | 最古・低速の単線などに限定 |
| ATS-S | 地上子による警報のみ |
| ATS-P | 速度パターンに基づく停止 |
| ATC | 地上から速度制限を車内表示・制御 |
| DS-ATC | 新幹線向けデジタルATC |
| ATACS | 無線を使った移動閉塞 |

### 最高速度（Max Speed）

路線の設計最高速度。曲線・勾配・レール規格・保安装置によって決まる複合値。

| 区分 | 速度目安 |
|---|---|
| ローカル線 | 〜85km/h |
| 地方幹線 | 85〜120km/h |
| 主要幹線 | 120〜160km/h |
| 高速線 | 200〜360km/h |

## ゲームへの取り込み方針

### Phase 1での導入候補

Phase 1（鉄道経営の核）で最初に意味のあるトレードオフを生む規格セット。

- **軌間**: 路線と車両の基本互換条件。違反は入線不可。
- **電化方式**: 非電化か電化か、電化方式の種別。動力源の基本制約。
- **軸重**: 路線の許容軸重と車両の軸重。超過は入線不可。
- **最高速度**: 路線の設計速度。車両の最高速度との組み合わせで実効速度が決まる。

レール規格（kg/m）と保安装置はPhase 3（鉄道工学）での詳細化を想定し、Phase 1では最高速度と軸重への影響として間接的に含める。

### データ構造の方針

規格値は原則としてコードに埋め込まず、`data/` 以下のJSONファイルで定義する。

TypeScript側では値の型のみ定義し、実際の規格カタログはJSONから読み込む。

```
data/
  rails/          ← レール規格データ
  vehicles/       ← 車両データ
  infrastructure/ ← 信号・保安装置データ
  eras/           ← 年代・技術ツリー
```
