# 検証用UIの表示規約

検証専用の補助UIは、その部分だけを「検証用UI」と分かる表示にする。2026-11-11のユーザー指定を正本とする。

## 適用範囲

試験マップ専用のタイトル・移動欄、試験条件の設定、試験車の配置・初期化、一時的な診断パネルなど、本番用UIに追加した検証専用の部分へ適用する。通常プレイでも使う共通の操作パネルや、検証に使っているだけの本番UIは対象にしない。

例えば「東上線｜近似再現（番線・短編成は仮設定）」と駅移動欄を囲む補助部分が対象である。画面全体のテーマ変更、常設の検証帯、本番UIの別デザインへの置換は行わない。

## 表示と実装

- 対象部分に小さな「検証用UI」ラベルを付ける。色だけで区別しない。
- 淡い黄土色の背景と破線の枠を使い、検証用の範囲を局所的に囲む。
- 対象の既存タイトル・操作を維持し、ラベルや装飾が操作・地図表示を妨げないようにする。
- 新設・改修する検証用UIでも同じ表現を使う。画面ごとに独自の色や別名称を増やさない。
- シミュレーションを操作する場合は本番と共通のゲーム操作命令を使う。表示の区別のために別のゲームロジックを作らない。

既存実装は [main.ts](../src/main.ts) の専用マップナビゲーションと [style.css](../src/style.css) の `.map-bookmarks.review-helper`・`.review-helper-badge` を参照する。ラベルは実際のDOM要素として追加し、補助部分には用途の分かるアクセシブルな名前を付ける。

地図移動欄での例:

```html
<div class="map-bookmarks review-helper" role="region" aria-label="検証用の地図移動補助">
  <span class="review-helper-badge">検証用UI</span>
  <!-- 既存のタイトル・移動操作 -->
</div>
```

現状の背景・枠のセレクタは地図移動欄向けである。他のパネルへ適用するときは、必要な外観を共通の `.review-helper` へ切り出して再利用し、地図用の絶対配置・幅・余白を他のパネルへ流用しない。既存の全検証用パネルに適用済みであるとは扱わない。

## 確認と引き継ぎ

検証用の部分だけが囲まれ、通常操作は従来の表示を保つこと、狭い表示幅でもラベルと操作が重ならないことを確認する。試験を合格したという意味の表示には使わない。外観の人間確認と、実装・機械検査の結果はTaskで区別して記録する。

今回の適用例は [東上線の短編成試験](features/tojo-playable-trial.md)、作業記録は [Task](tasks/2026-11-11_distinguish-review-workspace.md)を参照する。
