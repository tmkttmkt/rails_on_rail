# Design: 参考作品に基づく地図UI

## 参照する要素

- Rule the Waves 3: 灰色基調の業務ソフト的な外観、情報を枠と表で整理する構成、装飾より状態表示を優先する姿勢
- NIMBY Rails: 地図を主画面とし、上部の機能切替と地図上の小さな編集パネルで操作する構成

外観を複製せず、Rails on Railの線路敷設に必要な情報へ適用する。

## 決定

- 地図を画面の主領域にし、左右のパネルで地図幅を恒常的に狭めない。
- 上部をタイトル、機能区分、座標表示に使う。
- 線路敷設設定は地図左上の小さな工事パレットへまとめる。
- 選択情報は地図右上の小さな情報パネルへまとめる。
- 操作結果とショートカットは下部ステータスバーへ表示する。
- 装飾用の英語大文字見出し、発光、カード型指標を廃止する。
- 灰色の面、1pxの境界線、四角いボタンを基本とする。
- 通常線路は濃灰、建設中は青、選択は赤、吸着は緑とし、状態色の意味を固定する。

## 対象外

- メニュー項目の全機能
- パネルの移動、サイズ変更、ドッキング
- 最終的なアクセシビリティ設定とテーマ切替
