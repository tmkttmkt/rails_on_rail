# Design: 線路の延長操作と途中分岐

> 曲線生成方式は[円弧チェーンによる曲線敷設](circular-arc-track-building.md)、現在の接続規則は[N本からM本への接続対応調整](bundle-connection-alignment.md)に置き換えられた。本書は初期方式の判断履歴として残す。

## 直線

直線モードは始点と終点だけを受け取り、2点目で自動確定する。1つの線路内へ3点以上を追加できないため、折れ線状の角を作らない。

## 曲線

曲線モードは点を追加しながらCatmull–Rom曲線をプレビューする。`Enter`で確定し、制御点間を滑らかに接続する。

## 既設線路への吸着

ポインターから既設線路の描画用サンプル線分へ最近点を求める。画面上12px以内なら、その点を新線の始点として使用する。

吸着は端点だけでなく線分途中にも作用する。現段階では既設線路をデータ上で分割せず、分岐線の始点座標を既設線路上へ一致させる。線路グラフを導入する段階で、交点ノードと線路分割を実装する。

## 接線方向の維持

吸着位置を求めた描画用線分から、正規化した接線ベクトルも取得する。

- 直線モードでは、終点を接線の延長線上へ射影する。
- 曲線モードでは、最初のスプライン区間の微分方向を接線へ一致させる。
- 接線は双方向として保持し、次の制御点との内積から進行方向を選ぶ。

これにより、新線が接続地点で折れ曲がらず、既設線路と同じ方向で始まってから曲がる。

## 表示

吸着可能な位置にはリングを表示する。新線の最初の点を置く前だけ吸着を有効にし、以降の制御点が意図せず既設線路へ寄ることを防ぐ。
