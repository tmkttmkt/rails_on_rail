# Design: 路線・系統・経路・運行・運用のUI/UX

## 画面構成

```text
路線・系統 | 経路 | 運行 | 運用 | 車両
```

ボタンは平面的な標準ボタンとし、立体影・グラデーション・押し込み変形を使わない。

## 路線・系統

左側に路線一覧、右側に選択路線の系統一覧を表示する。系統編集項目は名称、略称、色、説明、表示順。色未指定時は「路線色を使用」と表示する。

路線または系統から「この区分で経路を作成」を押すと経路画面へ移動し、最初の区間の路線・系統を事前選択する。運行は直接作らない。

## 経路

経路名、方向、順序付き地点、停車・通過、番線・停止位置、物理経路、区間別路線・系統を編集する。地図上に探索結果と不接続箇所を表示する。反対方向は「反対方向の経路を複製」で別実体を作成し、必ず再検証する。

## 運行

経路を選択して、運行番号・名称・適用日・曜日・例外日と各地点の着発時刻を入力する。経路地点は読み取り専用で表示し、停車駅や方向を変える場合は経路編集へ移動する。同じ経路から別時刻の運行を複製できる。時刻は「翌 00:20」「2日後 03:10」のように表示し、複数日越しを編集できる。

## 運用

運行を複数日を含む時刻順に追加し、任意の通常編成を割り当てる。前後運行の時間重複と、終着・始発の駅・番線一致を行ごとに表示する。未割り当て運用も保存可能だが発車操作は無効にする。日別の運用実施画面では、その日だけ編成を差し替えられる。

## ヘルプ表記

「経路＝走る場所」「運行＝走る日時」「運用＝担当する編成」という説明をヘルプと初回案内に掲載する。通常のタブ名や作成ボタンには説明文を付加せず、「経路」「運行」「運用」の短い表記を維持する。

## 車両からの発車

配置編成を選ぶと、その配置駅・線路・向きと開始日時に適合する運用だけを選択可能にする。不適合候補も隠さず、理由付きで無効表示する。

## 削除確認

参照中の実体は削除ボタンを無効化し、参照している経路・運行・運用を一覧表示する。連鎖削除は提供しない。
