# Design: UIエリアの役割定義とナビゲーション構造

## 背景と問題

現行UIは3エリア（上・左・右）の役割が混在している。

| エリア | 現状 |
|--------|------|
| 上 | ブランド名・機能区分文字列・座標（構造的な役割なし） |
| 左 | ツール選択とツール固有設定が混在 |
| 右 | 選択情報・束/駅操作・運行管理が混在 |

## 決定: エリアの役割

### 上UI — モードナビゲーション

アプリ全体のモードを切り替えるタブと、常時アクセス可能なグローバルボタンのみを置く。
座標・ズームはマップヘッダー（地図直上の帯）に残す。

```
[Rails on Rail]  地図  建設  路線  運行  施設  車両  経営  統計    [💾] [⚙] [?]
                                ↑未実装タブはグレーアウト
```

タブの役割と実装状況:

| タブ | 役割 | 実装状況 |
|------|------|---------|
| 地図 | モードなし。マップ全体の俯瞰。パン・ズームのみ | Phase 0 |
| 建設 | 線路・駅の敷設と編集 | Phase -1 ✅ |
| 路線 | 路線定義・ダイヤ編成 | Phase 1 |
| 運行 | 列車の配置・発車・リアルタイム監視 | Phase 0（試作あり）|
| 施設 | 駅詳細・車庫・保安設備・信号（後で細分化） | Phase 2以降 |
| 車両 | 保有編成・保有車両の管理 | Phase 2以降 |
| 経営 | 財務・事業計画・投資 | Phase 4以降 |
| 統計 | 旅客数・収益推移・路線実績 | Phase 4以降 |

グローバルボタン:
- 💾 セーブ（セーブ管理ダイアログを開く）
- ⚙ 設定（将来）
- ? ヘルプ（将来）

### 左UI — 現在モードのツールと設定

アクティブなタブに応じてパネル全体の中身が切り替わる。

| モード | 左パネルの内容 |
|--------|--------------|
| 地図 | なし（またはビュー設定のみ） |
| 建設 | ツール選択（線路/駅/選択/移動）＋ツール固有設定 |
| 路線 | 路線選択・ダイヤ編集ツール（将来） |
| 運行 | 経路選択・列車配置・発車操作 |
| 施設 | 施設配置・編集ツール（将来） |
| 車両 | 車両・編成管理操作（将来） |
| 経営 | 財務操作（将来） |
| 統計 | フィルター・集計期間選択（将来） |

### 右UI — コンテキストパネル

モードと選択状態に応じて切り替わる。

| モード | 右パネルの内容 |
|--------|--------------|
| 地図 | マップサマリー（線路数・駅数・経路数・運行中列車数） |
| 建設 | **選択インスペクター**。選択なし→ヒントのみ。線路選択→線路詳細+束操作。駅選択→駅詳細+駅操作 |
| 路線 | 選択路線の詳細（将来） |
| 運行 | 路線網サマリー（経路一覧・列車状態・運行統計） |
| 施設 | 選択施設の詳細（将来） |
| 車両 | 選択車両/編成の詳細（将来） |
| 経営 | 財務サマリー（将来） |
| 統計 | 集計結果（将来） |

## 実装方針

### モード状態

```typescript
type AppMode = "map" | "construction" | "route" | "operation" | "facility" | "vehicle" | "management" | "statistics";
let appMode: AppMode = "construction"; // 初期値
```

### タブの有効/無効

実装済みモードのみ有効にする。未実装タブはクリック不可（`disabled`）でグレーアウト表示。
有効化対象: `map`, `construction`, `operation`（Phase 0完成時点）

### パネル切替

`setMode(next: AppMode)` 関数でモードを変更し、左右パネルの `hidden` を切り替える。
現行の `setTool()` は建設モード内のツール切替として残す。

## 対象外

- 未実装タブの中身の実装
- タブをまたぐデータフロー（例: 建設で敷いた線路を路線モードで参照する方法）
- 施設タブの細分化（保安・信号等を独立させるかは後続Designで決める）

## 2026-11-10 建設と施設の境界

新駅・新操車場など駅グループの部品の新設・拡張・撤去は建設。駅グループの作成修正、既存駅・操車場の名称・所属・用途領域など物理変更を伴わない編集は施設に置く。施設タブの左パネルは構内グループと領域編集、右パネルは選択施設の情報・名称・用途を扱う。独立した地図上の入口や重ね置き編集パネルは増やさない。操車タブの移動は今回対象外。
