# Design: 経路の作成と物理経路探索

## 目的

停車駅・通過駅、方向、番線、停止位置、物理走行列を `Route` として作成する。日時と編成はこの画面では扱わない。

## 作成手順

1. 経路名と方向名（「上り」「下り」等）を入力する。
2. 地図または駅一覧から地点を順番に追加し、停車・通過、番線、停止位置を指定する。
3. 隣接地点間を、端点位置だけでなく接線方向も一致する接続グラフで探索する。
4. 候補経路をプレビューし、必要なら分岐候補を選び直す。
5. 事前確認（接線適合性・最小曲線半径など）後に保存する。
※路線や系統が存在しなくても単独で作成・保存できる。

## 探索規則

- 幾何学的に交差するだけの線路は接続とみなさない。
- 接続点が同じでも接線方向が許容角を超える場合は通行不能とする。
- 逆走やスイッチバックは明示指定がない限り候補から除外する。
- 各 `RouteLeg` は通過線路、進行方向、ジャンクションを保存し、後から同じ経路を再現できるようにする。
- 一部legが探索不能なら経路全体を確定できない。

## 確定前確認結果

- 地点ごとの駅・番線・停止位置
- legごとの接続可否と物理距離
- 経路全体の最小曲線半径
- 参照施設一覧
