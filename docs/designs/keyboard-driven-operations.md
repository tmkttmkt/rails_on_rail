# Design: キーボード操作の全面拡張

## 設計方針

- **コンテキスト優先**: 今の状態（モード・ツール・選択）に応じて同じキーが異なる意味を持つことを許容する。ただし衝突は原則禁止。
- **テキスト入力との分離**: `<input>`, `<select>`, `<textarea>` にフォーカスがある間はゲームキーを無効にする（既存の `isTextEntryTarget` を活用）。
- **修飾キー区別**: `Ctrl+`/`Alt+` を組み合わせることでグローバル操作と建設操作を分離する。
- **発見可能性**: ショートカットはUIのボタンラベルかツールチップで表示する。覚えさせるより「気づける」設計にする。

## キーマップ

### グローバル（常時有効）

| キー | 操作 | 備考 |
|------|------|------|
| `Ctrl+S` | セーブダイアログを開く | |
| `F1` | 地図モード | |
| `F2` | 建設モード | |
| `F3` | 路線モード | 未実装時は無効 |
| `F4` | 運行モード | |
| `F5` | 施設モード | 未実装時は無効 |
| `F6` | 車両モード | 未実装時は無効 |
| `F7` | 経営モード | 未実装時は無効 |
| `F8` | 統計モード | 未実装時は無効 |

### ビュー操作（常時有効、テキスト入力時を除く）

| キー | 操作 |
|------|------|
| `W` / `↑` | マップを上へスクロール |
| `S` / `↓` | マップを下へスクロール |
| `A` / `←` | マップを左へスクロール |
| `D` / `→` | マップを右へスクロール |
| `Q` | 画面を反時計回りに回転（15度刻み）|
| `E` | 画面を時計回りに回転（15度刻み）|
| `+` / `=` | ズームイン |
| `-` | ズームアウト |
| `H` | 原点へリセット（位置・ズーム・回転） |

スクロールと回転は押しっぱなしで連続移動（`requestAnimationFrame` ループで処理）。
スクロール速度はズームに反比例させる（ズームアウト時は広く動く）。
回転はステップ制（15度刻み）と連続回転（長押し）のどちらが良いかは実装で検証する。

`Camera` 型に `rotation: number`（ラジアン、0 = 北向き）を追加し、`worldToScreen` / `screenToWorld` および renderer での Canvas2D 描画に回転を反映させる。

### 建設モード — ツール切替

| キー | ツール |
|------|--------|
| `T` | 線路を敷設 |
| `B` | 駅を設置 |
| `V` | 設備を選択 |
| `P` | マップを移動 |

### 建設モード — 線路敷設中（既存 + 追加）

| キー | 操作 | 実装 |
|------|------|------|
| `Enter` / `Space` | 敷設を確定 | ✅ |
| `Backspace` | 最後の点を戻す | ✅ |
| `Escape` | 敷設を取消 | ✅ |
| `Tab` | 直線 ↔ 曲線 切替（接続調整前）/ 接続先候補を切替（接続調整中） | 追加/✅ |
| `[` | 同時敷設本数 −1 | 追加 |
| `]` | 同時敷設本数 +1 | 追加 |
| `N` | 接続対応を左へ | ✅ |
| `M` | 接続対応を右へ | ✅ |
| `0` | 接続対応を中央へ | ✅ |

`Tab` のコンテキスト分岐:
- 始点をまだ置いていない、または始点が既設線の終端でない → 直線↔曲線切替
- 始点を既設線の終端に置いた後（`draftStartConnectionTrackId` が設定されている）→ 接続先候補を切替

### 建設モード — 選択中

| キー | 操作 | 実装 |
|------|------|------|
| `Delete` / `Backspace` | 選択した線路・駅を撤去 | ✅ |
| `Escape` | 選択を解除 | 追加 |

### 運行モード（将来）

| キー | 操作 |
|------|------|
| `Enter` | 列車を配置・発車 |
| `Escape` | 選択を解除 |

## 実装方針

### keybindings.ts の拡張

`KeyAction` 型にグローバル・ビュー・ツール切替の各アクションを追加する。
コンテキスト型も拡張する:

```typescript
type KeyContext =
  | "global"           // 常時
  | "view"             // ビュー操作（常時、テキスト入力除く）
  | "construction"     // 建設モード全般
  | "track-building"   // 線路敷設中
  | "selection"        // 選択中
  | "connection-adjustment"; // 接続調整中（既存）
```

### マップスクロールの実装

`keydown` でフラグを立て `keyup` でクリアする。`requestAnimationFrame` ループ内でフラグを見てカメラを移動する（既存の `frame()` 関数内に組み込む）。

```typescript
const pressedKeys = new Set<string>();
window.addEventListener("keydown", (e) => pressedKeys.add(e.key));
window.addEventListener("keyup", (e) => pressedKeys.delete(e.key));
// frame() 内で:
const panSpeed = 300 / camera.zoom; // ズームに反比例
if (pressedKeys.has("w") || pressedKeys.has("ArrowUp")) camera.y -= panSpeed * dt;
```

### 既存コードへの影響

- `keydown` ハンドラを整理し、コンテキスト判定を一か所にまとめる
- `isTextEntryTarget` は既存のまま活用
- ツール切替キーは `setTool()` を呼ぶだけ

## 衝突一覧（確認済み）

| キー | 用途A | 用途B | 解決 |
|------|-------|-------|------|
| `Backspace` | 最後の点を戻す | 選択を削除 | コンテキストで分岐済み |
| `Escape` | 敷設を取消 | 選択を解除 | コンテキストで分岐（追加時に対応） |
| `Tab` | 直線↔曲線切替 | 接続先候補切替 | コンテキストで分岐（`draftStartConnectionTrackId` の有無） |
| `Q` / `E` | 画面回転 | ツール候補 | ツール切替を `T`/`B`/`V`/`P` に割当て回避 |
| `S` | マップ下スクロール | 駅ツール候補 | 駅ツールは `B` に割当て回避 |

## 対象外

- キーバインドのカスタマイズ（設定画面）
- IME入力中の処理
- ゲームパッド
