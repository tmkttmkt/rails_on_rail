# Design: マップのセーブ形式

## 決定

- 保存対象の正本はシミュレーションの`MapState`とする。
- JSONのトップレベルに`version`を必須とし、対応していない版は読み込まない。
- ブラウザ内の簡易保存には`localStorage`を使用する。
- 持ち出し用には同じJSONをファイルとして書き出し、ファイルから取り込む。
- 読込時はJSON構文、基本構造、有限な座標、線路ID、軌道カタログ参照を検証する。
- 読込に失敗した場合は現在のゲーム状態を変更しない。
- カメラ位置、選択状態、敷設中の線路はUI状態なので保存しない。

## 保存境界

```text
保存する
  MapState
    ├─ 完成済み線路
    ├─ 線路仕様
    ├─ 線路群
    ├─ 接続点と参加線路上の位置
    └─ 工学状態

保存しない
  カメラ、選択、カーソル、敷設途中、通知
```

## 将来

形式変更時は既存`version`の読み込み処理を残し、新版へ一方向に変換する。未知の新版を推測で読み込まない。
