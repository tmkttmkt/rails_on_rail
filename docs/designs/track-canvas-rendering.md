# Design: 線路のCanvas描画

## 決定

線路は縮尺に応じて描画詳細を切り替える。

- 低倍率: ネットワーク形状を優先し、一本の線路記号として描く。
- 中倍率: 軌道の下地と左右二本のレールを描く。
- 高倍率: 下地、枕木、左右二本のレールを描く。
- レール間隔は線路仕様が参照する軌間から求める。
- 枕木はゲーム状態へ個別保存せず、中心線に沿って描画時に配置する。
- 枕木の表示間隔は実物間隔そのものではなく、画面上で潰れない間隔へ間引く。
- 選択、建設中、吸着の状態色はUI Designの意味を維持する。

## 理由

常に実寸で描くと、通常の地図倍率では軌間と枕木が1px未満になり識別できない。線路の設備状態ではなく地図記号としての可読性を優先し、倍率に応じた最小画面幅を持たせる。

## 対象外

- レール断面ごとの見た目
- バラスト、スラブ、併用軌道など支持方式別の描き分け
- 分岐器、交差、橋梁、トンネルの専用描画
- 電化設備
