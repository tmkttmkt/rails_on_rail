# Design: 線路束の分岐成立条件と重複禁止

## 決定

- 新線束のうち最低一本が既設線と個別接続すれば、束全体の分岐を開始できる。
- 新線束の全線が既設束と対応する必要はない。
- 対応しない新線は、その地点から始まる未接続線として残す。
- 点での接触、端点共有、線路同士の交差は、重ねがけとはみなさない。
- 同一直線または同一曲線上で有限長の区間が一致する場合は、既設線への重ねがけとして建設を拒否する。
- 重複判定は線路の中心線同士で行う。

## 将来

近接並走、三線軌条、ガントレット軌道、工事中の仮線などは単純な重複とは異なる。これらを導入する際は、明示的な設備形式または特別な建設命令として扱う。
