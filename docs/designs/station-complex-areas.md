# 構内グループ・用途領域・停車可能区間

線路群TrackGroupは平行線路の編集単位であり、駅・車庫全体の所属を表さない。Stationは車両を止める区間の正本として維持する。その上にStationComplex（構内・車両基地グループ）とStationArea（用途領域）を置く。

StationAreaは親complexId、名称、役割、線路上の距離区間群、任意のstationId、設定根拠と注記を持つ。役割はホーム、留置、引上げ、検修作業、保守、分岐・咽喉、接続通路、用途未確認。所属は線路全体ではなく区間で排他的に持ち、同じ線路を途中で分割できる。領域の面表示は区間から生成する可視化であり測量境界ではない。

停止可能な役割の領域にはStationを関連付ける。関連付けがない場合は分岐支障・他の停車場を除いた範囲から作る。ホームは既存旅客駅を関連付ける。通路・咽喉・未知用途の領域には留置区間を作らない。引上げの区間は一時停止用であり長期留置配置を拒否する。用途を付けただけで現地用途を確定したとは扱わず、layout（ゲーム上の仮区分）とsource（資料上の対応）を区別する。

共通命令で親作成、領域作成・名称変更・用途変更・所属変更・分割を行う。範囲重複、親と関連駅の欠落、関連停車範囲の領域外への逸脱を拒否する。分割は元区間の完全な分割とし、線路・接続の敷設や削除をしない。運転中・車両配置中の構造変更と、運用から参照される停車場の再編は拒否する。

MapState v15へ階層とIDカウンタを追加する。v14以前は空の階層を追加して移行する。既存旅客駅のIDと範囲は維持する。

東上線は既存車庫マップから別の領域マップを生成する。川越市は全関連線路の領域を明示し、残余を通路として保持する。他の既存施設も親グループへまとめ、広すぎる線群は幾何上の平行・重なりで分ける。未確認の用途や進入経路は注記し、実車の運用可能を断定しない。
