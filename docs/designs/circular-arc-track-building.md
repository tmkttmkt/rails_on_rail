# Design: 円弧を連ねる曲線敷設

## 決定

曲線敷設の正本をCatmull–Romスプラインの制御点列から、順番に確定される線形区間の終点列へ変更する。

- 最初の2点で初期進行方向を決める。
- 既設線路から開始する場合は、その線路の接線を初期進行方向にする。
- 以後の各点まで、現在位置と現在方向に接する一定半径の円弧を生成する。
- 円弧の終端方向を次の区間の開始方向として引き継ぐ。
- 新しい点を追加しても、既に確定した区間を変形させない。
- ほぼ直進方向にある点までは直線として扱う。

これにより、通常区間は「直線または一定半径の円弧」の列となり、半径表示がプレイヤーの操作と直接対応する。

## 既設線路への接続

開始方向と接続先方向を一つの円弧だけで同時に満たせない場合がある。初期実装では最終区間だけ両端方向を満たす接続曲線を使用する。将来は二円弧接続または緩和曲線を含む線形へ置き換える。

## 対象外

- クロソイドなどの正式な緩和曲線
- 円弧間の曲率変化を許容範囲へ収める自動調整
- 敷設後の区間単位編集
- 分岐器固有の線形
