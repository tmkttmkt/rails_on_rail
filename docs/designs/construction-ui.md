# Design: 建設モードUI再設計

## 決定事項

### ツール構造

建設モード内の「設備を選択」ツールと「マップを移動」ツールを廃止する。

| 旧ツール | 変更 |
|----------|------|
| 線路を敷設 | 存続 |
| 駅を設置 | 存続 |
| 設備を選択 | **廃止 → デフォルト状態へ** |
| マップを移動 | **廃止 → キーボード/マウスで常時利用可能** |

### デフォルト状態（カーソルモード）

建設ツールを何も選んでいない状態。

- 地図上のクリック → 最も近い線路・駅を選択
- 何もない場所のクリック → 選択を解除
- ドラッグ → マップをパン
- `Escape` または右クリック → 建設ツールを抜けてデフォルトに戻る

専用の「選択ツール」ボタンは不要。デフォルト状態が選択の役割を担う。

### 建設ツール一覧

現在と将来を含めた一覧。ツールは必要に応じて追加する。

| ツール | 状態 | 概要 |
|--------|------|------|
| 線路 | ✅ 実装済み | 線形区間を敷設 |
| 駅 | ✅ 実装済み | 線路上に停車地点を作成 |
| 保安装置 | 将来 | 信号・閉塞・ATS/ATC等を設置 |
| （その他） | 将来 | 車庫、電化設備、踏切 等 |

## 左パネルのレイアウト

### デフォルト状態

ツールボタンのみ表示。選択情報は右パネルに出る。

```
[線路]  [駅]  [保安装置…]
```

### 線路ツール選択時

```
[線路]  [駅]  [保安装置…]   ← ツールボタン（線路がアクティブ）

直線 | 曲線               ← 線形切替（Tab でも切替可）
同時敷設本数  [−][1][＋]

軌間          [1067 mm ▼]
レール形式    [JIS 50N ▼]
軌道支持方式  [PC枕木・バラスト▼]
路盤          [強化路盤   ▼]
設計速度      [80] km/h

─────────────────────
曲線半径 / 接続情報エリア  ← 状況に応じて表示
─────────────────────
[敷設を確定]               ← 2点以上のとき有効
[最後の点を戻す]
[取消]
```

軌間・レール・支持・路盤の4つは「詳細設定」として折りたたみ可能にすることを検討する（頻繁に変更しないため）。折りたたみかどうかは実装時に決定する。

### 駅ツール選択時

```
[線路]  [駅]  [保安装置…]

対象: [一本のみ] [束すべて]
```

### 将来のツール

各ツールが必要な設定を左パネルに追加する。設計は各ツールのDesign文書で定義する。

## 右パネルのレイアウト（建設モード）

選択インスペクター。選択状態に応じて内容が変わる。

### 何も選択していない

```
地図状態
  TRACKS  STATIONS  POINTS
  0       0         0
```

### 線路を選択

```
地図状態
  TRACKS  STATIONS  POINTS

─────────────
線路 3
直線 · 接続 2箇所 · 単独線路
1067 mm軌間 / JIS 50N / …
最小半径 ∞ · 設計 80 km/h

[束を作成]  [束へ追加]
[束から外す][束を解体]

[選択した線路を撤去]
```

### 駅を選択

```
地図状態
  TRACKS  STATIONS  POINTS

─────────────
新宿駅
駅 1 · 停車地点 2箇所

[駅名変更]  [駅を延長]
[駅を統合]  [駅を撤去]
```

## 操作フローの変化

### 現在

1. 「設備を選択」ツールに切り替える
2. 線路・駅をクリックして選択
3. 右パネルの操作ボタンを押す

### 変更後

1. **Escape** で建設ツールを抜ける（またはそのままデフォルト状態）
2. 線路・駅をクリックして選択
3. 右パネルの操作ボタンを押す

ツール切替の手順が1ステップ減る。

---

## 対象外

- 保安装置ツールの詳細仕様
- 軌間・レール等の詳細設定折りたたみUIの実装方法
- 線路ツール内の直線/曲線以外の線形種別（クロソイド等）
