# Design: 線路の水平線形、曲線半径、カント

## 決定

- プレイヤーは工学上の最小曲線半径に制限されず、自由な形の曲線を敷設できる。
- ワールド座標は`1 unit = 1 m`として扱う。座標キーは`x`、`y`のままとし、値の意味をメートルに統一する。
- 曲線半径は入力値ではなく、線路形状から求める派生値とする。
- 曲線上の各位置について局所曲線半径を求め、区間全体では最小曲線半径を保持・表示する。
- 複線以上では中心線だけでなく各線の半径を求め、通過可否や速度判定には最も厳しい線の値を使う。
- カントは通常のマップ描画では表示しないが、線路の内部データとして保持する。
- カントは建設前に設計速度などから自動提案し、建設確定時の設備状態として保存する。
- 建設後に線路形状を変更してもカントを暗黙に変更しない。必要ならカント改修工事または速度制限を発生させる。
- 急曲線そのものは禁止せず、車両の通過可否、速度、摩耗、安全性、法令適合へ不利な結果を与える。

## 形状と工学値の分離

線路形状の正本は、プレイヤーが順番に確定した線形区間の終点と、それから生成される連続曲線である。現在の曲線生成方式は、通常区間を一定半径の円弧として順次確定する円弧チェーンである。詳細は[`circular-arc-track-building.md`](circular-arc-track-building.md)を参照する。

曲線長、曲率、局所曲線半径、最小曲線半径は形状から再計算できるため、正本にはしない。保存する場合もキャッシュとして扱い、形状変更時に再計算する。

```text
制御点
  ↓ 曲線生成
線路形状
  ↓ 数値サンプリング
距離・曲率・局所曲線半径・最小曲線半径
```

直線部分は曲率`0`、曲線半径は無限大として扱う。曲率が非常に小さい箇所は、表示上「直線」としてよい。

## 自由敷設と無効な形状

ゲームは「半径が小さすぎる」という理由だけでは建設を拒否しない。軽便鉄道、森林鉄道、路面軌道、構内線など、低速を受け入れて急曲線を使う選択肢を残すためである。

建設を拒否するのは、工学的に不利な形状ではなく、計算不能または線路として成立しない形状に限る。

- 連続する制御点が同一またはほぼ同一
- 長さがほぼゼロの区間
- 一点で進行方向が反転する形状
- 曲率計算が有限値にならない形状

急曲線には建設後の結果を与える。車両ごとの最小通過半径を満たさなければ通過不可とし、通過可能でも許容速度低下、摩耗増加、脱線リスク、法的な制限の対象になり得る。

## 複線以上の曲線

並行する線路は中心線からの単純な見た目のずらしだけではなく、各線を独立した走行経路として評価する。同じ曲線でも内側線は半径が小さく、外側線は半径が大きい。

表示では、敷設中にカーソル位置の局所曲線半径と、現在の形状における最小曲線半径を示す。複線以上では原則として最小となる線の値を主表示し、詳細表示で各線の値を確認できるようにする。

## カント

カントは左右レールの高低差をミリメートルで表す。通常表示には使わないが、速度判定と保守判断に用いる。

カントは曲線全体で一つの値とは限らないため、将来の永続データは線路上の距離に対する分布を表現できる形にする。具体的なキー構造は実装Taskで確定する。

```text
線路上の距離 → カント量（mm）
```

建設時には、曲線半径、設計速度、軌間、想定する列車条件から推奨値を求める。ただし自動提案値は現実の設備として建設後に固定される。運行速度が変わっただけで設備のカントが自動的に変化してはならない。

速度判定では、曲線半径だけでなく、実カントと当該列車・速度に必要なカントとの差を用いる。カント不足とカント過剰の許容値は車両、線路規格、法的状態、特例認可によって変えられる設計とする。

## 今後決めること

- 曲率を安定して求めるサンプリング間隔と数値計算法
- 円弧間へどの方式の緩和曲線を挿入するか
- 推奨カント、カント不足、カント過剰、曲線速度の計算式と係数
- 車両の最小通過半径と曲線通過性能のデータ構造
- 曲線、勾配、軌道状態、軸重を統合した最終的な速度判定順序

縦断線形、勾配、縦曲線は本Designの対象外とし、水平線形とは別に設計する。
