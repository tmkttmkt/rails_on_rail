# Design: N本からM本への接続対応調整

## 決定

N本の既設束からM本の新線を伸ばす場合、接続する線路は左右順を崩さず、最低一本が重なる全配置を候補とする。候補数は次で求める。

```text
候補数 = N + M - 1
```

初期候補はクリックした既設線路を基準にする。既設束の左半分を選んだ場合は、その線路から束の中央方向である右側へ新線を並べる。右半分を選んだ場合は左側へ並べる。奇数本の中央線を選んだ場合だけ中央寄せとする。

始点を既設線路へ吸着した後、`N`で左、`M`で右の候補へ一段移動する。範囲端ではそれ以上移動しない。

選択候補は敷設中プレビューと`track.create`の確定処理へ同じ候補番号として渡す。接続されなかった線路は削除せず、既設線または新線の未接続線として残す。

## 例

5本から2本では6候補、2本から5本でも6候補を生成する。中央付近では二本が接続し、左右端では一本だけが接続する。接続しない線路はそのまま余る。

既設5本の一番左の先端から新線3本を伸ばす場合、選択線、左から2本目、中央線へ対応させる。一番右の先端を選んだ場合は左右反転する。

## 対象外

- 非連続な対応
- 接続確定後の再編集
- カーソル位置による自動候補変更

## 直線モードの接続制限

直線モードで既設直線から始める場合は、その先端から方向を維持して延長する。既設直線の途中から直線を生やすことはできない。一方、既設曲線の途中からは、その地点の接線方向へ直線を生やせる。終点側は延長軸と既設線の方向が一致する先端だけへ接続する。
