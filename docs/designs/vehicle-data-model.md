# Design: 車両設計と接続互換性

## 決定

- メーカー設計を機関車、動力車、客車、貨車の別カタログへ置く。
- ファイル分類から挙動を決めず、`capabilities`を判定に使う。
- プレイヤー会社形式と車両個体は、メーカー設計を参照する保存データとする。
- 車両の前後端へ連結器と貫通ブレーキ方式を持たせる。
- 機械連結可否と貫通ブレーキ互換性を別々に返す。
- 貫通ブレーキを必須とするかは、路線・運行・法制度側の方針として判定時に渡す。
- ホワイト式などの表記は表示専用とし、軸グループを物理計算の正本とする。
- 編成は向き付き車両個体の順序列、列車は向き・行先付き編成の順序列とする。
- 車両は同時に一編成、編成は同時に一列車だけへ所属できる。
- 連結器不適合は構成操作を拒否し、ブレーキ不適合は警告として保持する。

## 接続判定

隣接する2両について、前車の後端と後車の前端を比較する。

```text
連結器が直接互換
  → 機械連結可能

両端に共通する貫通ブレーキ方式がある
  → 貫通ブレーキ動作可能

運用方針が貫通ブレーキ必須、かつ共通方式なし
  → 編成不適合
```

手ブレーキは車両単体の停止・留置用装備であり、貫通ブレーキ互換性には使用しない。

## ブレーキなし車両

歴史的な貨物列車や低速の産業・末端路線を表現するため、貫通ブレーキを持たない車両を一律に連結不能にはしない。機械的に連結可能であれば編成へ含められるが、本線など貫通ブレーキ必須の運用には適合しない。

法的に不適合な編成を実際に運行させるかどうかは、法的状態・違反システムで別に扱う。
