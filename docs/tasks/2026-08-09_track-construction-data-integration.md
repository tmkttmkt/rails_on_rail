# Task: 軌道構成データのゲーム統合

## 目的・背景

YAMLで定義したレール、軌道支持方式、路盤をプロトタイプから読み込み、敷設した線路へ構成IDを保存する。レール断面系統と軌道支持方式の不正な組み合わせをシミュレーション層で拒否できるようにする。

## 責任範囲

- YAMLカタログの型付き読込
- ID一意性と参照整合性の検査
- レールと軌道支持方式の互換性判定
- 線路作成命令とゲーム状態への軌道構成追加
- 敷設UIからのレール、支持方式、路盤選択
- 単体テストとビルド確認

## 対象外

- 軸重、速度、劣化の本格計算
- 建設費と維持費
- 電化方式と軌間のUI選択
- 既存セーブデータの移行機構

## 完了条件

- [x] YAMLカタログをゲームから読み込める
- [x] レール、支持方式、路盤の参照切れを検出できる
- [x] 非互換なレールと支持方式を拒否できる
- [x] 敷設した線路へ3種類のIDが保存される
- [x] UIから構成を選択できる
- [x] 関連テストとビルドが成功する

## 作業結果

- `yaml`パッケージでViteのraw importから4つのYAMLカタログを読み込む型付きカタログを実装した。
- 線路作成命令へ軌道構成を追加し、ゲーム状態へIDを保存するようにした。
- レールの断面系統と支持方式の互換性をシミュレーション層で検査する。
- 敷設UIへレール、軌道支持方式、路盤の選択欄を追加した。
- 現在仕様をFeature文書へ記録した。

## 検証結果

- `npm test`: 21テスト成功
- `npm run build`: TypeScript型検査とViteビルド成功
- YAML: 67レール、10支持方式、5路盤の読込をテスト
