# 東上線の旅客線路数不一致10駅を修正

目的: 公式構内図と不一致の10駅について、非旅客線・他社線の駅所属を直す。
範囲: 対象スナップショット専用の明示的な旅客線路設定、生成処理、再生成・監査・文書。
対象外: 線路の撤去、全駅ホーム端の実寸化、ホーム本体の描画変更、最新OSM再取得。
完了条件: 残す線路を配線位置と資料で説明できること、全46駅の数不一致が0、残す線形と元入力が不変、施設到達検証とビルドが成功すること。
検証: 再生成、全駅監査、型検査・テスト、修正前後の旅客線路・範囲・留置範囲差分。
関連: [監査](../research/tojo-station-shape-audit.md)、[マップ仕様](../features/tojo-depot-map.md)。

## 結果

[補正根拠と検証](../research/tojo-station-track-corrections.md)。10駅19範囲を除き113旅客範囲となった。全46駅の本数不一致0、極短範囲0。線路・分岐・残存旅客範囲と元入力の不変を比較確認した。生成・監査・ビルド成功、238テスト成功。

川越市旧工場側線7区間は誤所属線からの検証だったため到達確認を撤回し、施設名へ経路未確認を明示して保持した。残る95留置区間は到達検査成功。ホーム長と旧工場側経路は残作業である。

人間確認: `/?map=tojo-depots` を再読込し森林公園等の旅客帯を確認する。`/saves/osm-tojo-station-audit.html` で対象10駅の登録数と赤い範囲を確認できる。ゲームの目視確認は未実施。コミットはしていない。

文書リンクの存在確認成功。開発サーバーの地図JSONをHTTP取得し、全46駅が修正後の参照本数と一致することを確認した。

後続の[取込器修正](2026-11-08_fix-osm-passenger-platform-matching.md)で小川町の手動選択1本に誤りを検出し、track-164を戻しtrack-168を外した。全46駅の本数一致を再確認した。
