# 東上線・越生線の全旅客駅形状を監査

依頼: 駅の形がおかしい箇所が多くないか詳しく調べる。
対象: `saves/osm-tobu-tojo-depots.json` の全46旅客駅。元取込・生成コード・ゲーム描画・公開施設資料を照合する。現マップの修正・コミットはこの調査では行わない。
検査: 停車範囲長、座標と線路距離、分岐を跨ぐ範囲、同駅の端部のずれ、急角度・短い渡り線、側線の旅客化、実施設との差。
成果: 再実行可能な監査スクリプト、全駅数値、全駅図、確認済みの問題と疑いを区別した調査報告、原因と修正優先順位。
関連: [マップ](../features/tojo-depot-map.md)、[取込](2026-11-05_import-osm-railway-data.md)。最終的な現地配線照合は資料の範囲を明示する。

## 調査結果・検証

[全駅報告](../research/tojo-station-shape-audit.md)。46駅132範囲、公式図と線路数不一致10駅、80 m未満3範囲、最大180 m。座標誤差0.01 m超と範囲内分岐横断は0件。監査スクリプトを実行し、元地図のSHA-256不変を確認した。全46駅の公式構内図と監査HTMLを確認した。ゲームコードは本調査では変更していないためゲームテストは再実行していない。

未確認: ホーム端の実寸、全番線の対応、現地最新配線。人間確認は開発サーバーの `/saves/osm-tojo-station-audit.html` を開き、坂戸・朝霞・寄居等の赤い範囲と公式図を比較する。修正作業は別Taskとする。
