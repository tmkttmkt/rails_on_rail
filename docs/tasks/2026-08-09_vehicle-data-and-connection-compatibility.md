# Task: 車両データと連結・ブレーキ互換性

## 目的・背景

機関車、動力車、客車、貨車を別カタログとして定義し、隣接車両間の連結器と貫通ブレーキの互換性をシミュレーション層で判定できるようにする。

## 責任範囲

- 車両データ領域と初期カタログ
- メーカー設計、寸法、軸グループ、容量、動力、法的分類の共通構造
- 車両前後端の連結器・貫通ブレーキ装備
- 機械連結と貫通ブレーキの互換性判定
- YAML読込と参照整合性検査
- 単体テストと現在仕様文書

## 対象外

- プレイヤー会社形式と車両個体
- 編成編集UI
- 牽引力・走行抵抗・制動距離の計算
- 改造処理と法的認可処理
- 実在車両データ

## 完了条件

- [x] 4種類の車両カタログを分離して読み込める
- [x] 連結器とブレーキ方式の参照切れを検出できる
- [x] 前後端を指定して機械連結可否を判定できる
- [x] 共通貫通ブレーキの有無を判定できる
- [x] ブレーキ必須・任意の運用方針を区別できる
- [x] テストとビルドが成功する

## 検証方法

- `npm test`
- `npm run build`
- 全YAMLの重複キー、ID、参照整合性確認

## 作業結果

- `data/vehicles/`へ製造会社、連結器、ブレーキ、4種類の車両カタログを作成した。
- 軸グループ、表示用ホワイト式、能力、動力、前後端接続を持つ初期車両4件を追加した。
- YAMLを型付きで読み込み、ID、製造会社、連結器、ブレーキ参照を検査する`VehicleCatalog`を実装した。
- 機械連結と貫通ブレーキを分離した接続互換性判定を実装した。

## 検証結果

- `npm test`: 25テスト成功。
- `npm run build`: TypeScript型検査とVite本番ビルド成功。
- 同一連結器・真空ブレーキの機関車と客車が適合することを確認。
- ブレーキなし貨車が、任意運用では適合し、必須運用では不適合になることを確認。
- 異なる連結器が機械連結不能になることを確認。
