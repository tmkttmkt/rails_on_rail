# OSMの未確定駅を保持し欠落を解消する

目的: 調査で停止せず、事業者欠損等で駅そのものを消す不具合を修正する。
範囲: 未確定旅客駅の共通操作・保存v14・表示、局所ホームから一意に決まる事業者の解決、診断と元OSM再取り込み。
制約: 未確定駅へ列車を配置しない。複数事業者を推測で混ぜない。旧セーブを読めること。西大家・武州長瀬等も位置と名称を保持する。
検証: 未確定駅の保存往復・不正データ拒否・線路削除時の保持・統合・CLI欠損ケース、全テストとビルド、全46駅保持の実データ検査。
関連: [原因調査](../research/osm-missing-stations-causes.md)。

## 結果と検証

[設計](../designs/unresolved-import-stations.md) / [現在仕様](../features/osm-passenger-import.md)。未確定駅の共通操作・保存v14・地図ラベル・理由表示、属性や一意な局所対応による所属解決を実装した。

元OSM再取込で46駅の欠落0。従来欠落9駅のうち6駅は範囲を復元、寄居・西大家・武州長瀬は未確定として保持。既存車庫マップを上書きしていない。新URL `/?map=tojo-import&focus=みなみ寄居` で確認できる。

32ファイル257テストとビルド成功。保存往復、理由なし空駅の拒否、無関係な線路削除時の保持、車両配置拒否、統合、旧v13移行を追加検証した。CLIのホーム欠損テストは駅0件を成功とする旧期待値を廃し、駅の保持を検査する。

ブラウザーでみなみ寄居の選択・91 m停車範囲と地図ラベル、寄居の未確定ラベル・理由・駅への移動を確認した。表示確認の評価4/5: 位置・理由は見えるが寄居等の停車範囲自体は未確定。視覚的な最終判断はユーザー確認待ち。スクリーンショットは可視化フォルダーの `tojo-station-audit/restored-minami-yorii.png`。

残作業: 寄居の事業者所属の追加根拠、西大家のホーム端資料、武州長瀬の面表現対応、中板橋・和光市の部分不足。駅を消す処理でこれらを隠さない。コミットはしていない。
