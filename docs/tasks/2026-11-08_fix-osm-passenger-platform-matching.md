# OSM取込の旅客ホーム対応を修正

目的: 近傍側線・他社線・極短断片を旅客駅へ自動登録する不具合を取込器で防ぐ。
範囲: ホーム境界との局所的かつ継続的な対応、元wayの事業者・構内線タグ、ホーム端による範囲生成、未確定駅の診断、回帰テスト。
対象外: ホーム本体の描画、欠損OSMを推測で補完、既存手修正マップの上書き。
完了条件: 個別駅IDの例外なしで東上線の既知誤所属を再取込検査し、未確定を明示する。ホーム未提供時は近傍全線への登録を行わない。合成回帰テスト・全テスト・ビルド成功。
検証: 疎な頂点、他駅ホーム、横断・点接触、同じ側の余分な線路、事業者混在、分岐による極短範囲、ホーム欠損をテスト。元OSMを別出力へ取り込み、元セーブを保持して比較する。
関連: [駅監査](../research/tojo-station-shape-audit.md)、[個別修正](../research/tojo-station-track-corrections.md)。

## 結果と残作業

[現在仕様](../features/osm-passenger-import.md) / [調査・検証結果](../research/osm-passenger-platform-matching.md)。局所ホーム照合・事業者照合・ホーム端の投影・短区間拒否・未確定診断を実装した。全251テストとビルド成功。元OSMの別出力で再取込、保存再読込を実行した。

全46対象駅で35駅が本数一致、2駅が一部のみ、9駅は欠損等により未登録。従来の近傍全線による埋め合わせは行わない。小川町の前回手修正も1本訂正し、既存車庫マップの全46駅の本数一致を再確認した。個別修正マップを新取込の不完全なマップで上書きしていない。

未確定駅の資料補足・共用駅の事業者関係・relationホーム対応は後続作業。人間確認は診断ファイルの警告と元OSMホーム形状を比較する。コミットはしていない。

追加比較: 再取込の全線路・分岐接続点・転てつ器は元セーブと一致。既知の誤所属IDが対象10駅へ再登録されていないこと、元入力SHA-256不変、文書リンク、差分チェックを確認した。CLI統合テストはgeometry形式とnode参照形式の双方を確認する。
