# 操車基盤と試作ブランチを分離

ユーザー承認: 本体の基盤1コミットと、試作ブランチの実験1コミットに分け、本体へ戻して小さい問題から再開する。

mainにはfleet共通化、留置範囲モデル、接続判定と既存入換の整合を残す。中央固定シナリオ、混載手順生成、仮想ハンプ、簡易連動、26施設自動整形と観察UIはprototype/bekasovo-yardへ分離する。既存コミットに入っている二方面の固定入換試験は維持する。

全未コミットファイルを外部可視化ディレクトリへハッシュ付きで退避済み。両ブランチのテスト・ビルド・差分を確認し、本体で終了する。新しいゲーム仕様や次の機能はこの作業では確定しない。
