# Task: 曲線半径とカントのゲーム実装

## 目的・背景

自由曲線の操作性を維持したまま、線路形状をメートル単位の工学値として評価できるようにする。敷設中と選択時に曲線半径を確認でき、建設時の設計速度から算出したカントを線路状態として保存する。

## 責任範囲

- 既存軌間カタログのゲーム読み込み
- 各線の延長、局所曲線半径、最小曲線半径の計算
- 複線以上における最も厳しい半径の判定
- 敷設中の曲線半径表示
- 建設時の設計速度と推奨カントの保存
- 選択した線路の工学値表示
- 自動テストと現在仕様文書

## 対象外

- 緩和曲線
- 車両ごとの曲線通過可否
- カント不足・過剰による最終速度計算
- 曲線による摩耗、脱線、法的判定
- 建設後の線形編集とカント改修工事

## 完了条件

- [x] 曲線の局所半径と最小半径を計算できる
- [x] 複線では各線を個別に計算できる
- [x] 敷設中と選択時に最小半径を確認できる
- [x] 設計速度から推奨カントを計算し、建設済み線路へ保存できる
- [x] テストと本番ビルドが成功する

- `npm run build`
- ブラウザで敷設中と選択時の表示を確認

## 作業結果

- 軌間カタログをゲームへ読み込み、線路仕様に`gaugeId`を追加した。
- サンプル点列から延長、局所曲線半径、最小曲線半径を求める処理を実装した。
- 複線以上は全線を個別計算し、最も小さい半径を線路群の代表値にした。
- 敷設中にカーソル位置半径、最小半径、推奨カントを表示するようにした。
- 軌間、設計速度、最小半径から推奨カントを算出し、距離別プロファイルとして建設済み線路へ保存した。
- 選択した線路に最小半径、設計速度、カントを表示するようにした。
