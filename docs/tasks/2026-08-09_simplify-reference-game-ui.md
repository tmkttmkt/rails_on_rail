# Task: 参考作品に沿った単純な地図UI

## 目的・背景

暗色の装飾的なダッシュボードUIを廃止し、Rule the Waves 3の情報中心の外観とNIMBY Railsの地図中心操作を組み合わせた単純なUIへ変更する。

## 責任範囲

- 地図を主領域にする画面構成
- 工事設定と選択情報の小型パネル化
- 上部メニュー風領域と下部ステータスバー
- 状態色と線路描画色の整理
- 既存操作とDOM IDの維持
- ビルド、テスト、人間確認手順

## 対象外

- 新しいゲーム機能
- メニュー項目の機能実装
- レスポンシブ対応の完成

## 完了条件

- [x] 地図が画面の大部分を占める
- [x] 線路敷設に必要な設定へ引き続きアクセスできる
- [x] 選択、建設中、吸着の状態色を区別できる
- [x] テストと本番ビルドが成功する

## 検証方法

- `npm run test`
- `npm run build`
- ブラウザで敷設、選択、撤去、パン、ズームを確認

## 作業結果

- 左右パネルで地図を狭める3列構成を廃止し、地図全面へ小型パネルを重ねる構成にした。
- 上部へ機能区分と座標、下部へ操作状態を置いた。
- 英語の装飾見出し、発光、カード型指標を削減した。
- 灰色の業務ソフト風パネル、四角いボタン、細い境界線へ変更した。
- 通常線路を濃灰、建設中を青、選択を赤、吸着を緑へ変更した。
- 既存の操作要素とDOM IDは維持した。

## 検証結果

- `npm run test`: 4ファイル、41件成功
- `npm run build`: 成功
- `git diff --check`: エラーなし
- ブラウザ操作と視覚確認: 利用可能なブラウザがないため人間確認待ち
