# Task: AI生成マップの確定前に接続状態を確認する

## 目的・背景

AI生成マップが線形として描画できても、接続情報を持たない孤立線路や接続漏れが残る場合がある。確定前検査へトポロジー診断を加え、人間が保存前に判断できるようにする。

## 責任範囲

- 接続成分の一覧
- 接続点を持たない孤立線路の検出
- 未接続の始端・終端一覧
- 別の接続成分に属する他線路から2m以内にある未接続端を接続漏れ候補として検出
- 大規模AI生成マップの再検査

## 対象外

- 行き止まり線路の自動エラー判定
- 接続漏れの自動修復
- 意図した路線網を自然言語から推測する処理

## 完了条件

- [x] 半径検査APIがトポロジー診断も返す
- [x] 孤立線路と通常の未接続端を区別する
- [x] 座標上近い未接続端を接続漏れ候補として返す
- [x] 大規模マップを再検査して結果を提示する

## 実装結果

- `inspectTrackRadii`の応答へ`topology`を追加した。
- 接続の正本であるjunctionのportから線路グラフと端点接続状態を構築する。
- 同じ接続成分内の線路への近接は既存junctionによる位置ずれでも発生するため、接続漏れ候補から除外する。

## 検証結果

- `npm run build`: 成功。
- 保存済み大規模AI生成マップを再検査し、6接続成分、孤立線路`track-19`〜`track-22`、未接続端21件、別成分への2m以内の接続漏れ候補0件を確認した。
- 同じ成分内の接続済み線路を近接漏れとしていた初回の誤警告を除外した。

## 未確認事項・残作業

- `track-19`〜`track-22`を貨物ヤードの引上線または母線へ接続するか、意図した独立展示線として扱うかを決める。
