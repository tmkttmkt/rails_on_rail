# Task: 敷設中線路の終点吸着

## 目的・背景

敷設中の線路を既設線路へ接続し、自由な位置から既存の鉄道網へ線路を到達させられるようにする。

## 責任範囲

- 敷設中線路の終点吸着
- 吸着クリック時の自動確定
- 曲線終点の接線方向維持
- 終点吸着のプレビュー

## 対象外

- 交点ノードと既設線路のデータ分割
- 分岐器設備
- 直線で接続する際の両端接線を満たす線形計算

## 完了条件

- [x] 敷設途中に既設線路へ近づくと終点吸着候補が表示される
- [x] 吸着候補をクリックするとその位置で線路が確定する
- [x] 曲線の終点方向が接続先線路の方向と一致する
- [x] 自動テストと本番ビルドが成功する

## 検証方法

- 終端接線の曲線サンプリングテスト
- `npm run test`
- `npm run build`
- ブラウザで曲線を既設線路へ接続する

## 作業結果

- 始点配置後も既設線路への最近点と接線を追跡するようにした。
- 終点吸着時に接続座標と終端接線を線路データへ保存するようにした。
- 吸着候補のクリックで、直線・曲線とも自動確定するようにした。
- Catmull–Rom終端へ仮想制御点を追加し、接続先の接線方向へ一致させた。
- プレビュー、確定描画、選択判定で同じ終端接線を使用した。

## 検証結果

- `npm run test`: 12件成功
- `npm run build`: 成功
- 曲線終端の微分方向が指定接線へ一致することを自動テストで確認
- ブラウザ上の操作感: 人間確認待ち

## 未確認事項・残作業

- 実ブラウザで終点吸着の距離と自動確定が自然か確認する。
- 接続先線路のデータ分割とネットワーク接続は未実装。

## 引き継ぎ

画面を再読み込みし、曲線を途中まで敷設してから既設線路へ近づける。緑のリングをクリックし、接続直前の方向が既設線路と一致することを確認する。
