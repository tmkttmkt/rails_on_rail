# Task: 線路上の停車地点として駅を試作

## 目的

Phase -1本来の駅・経路探索・列車移動へ戻る最初の段階として、駅を独立施設とし、線路上の停車地点を持つ最小モデルと操作UIを作る。

## 責任範囲

- 駅と停車地点の状態モデル
- 一本の線路をクリックして駅を配置
- 駅名の表示、選択、改名、削除
- 線路上の二点による駅範囲指定と駅名入力ダイアログ
- 既存駅の範囲延長
- 束全体への駅範囲一括設定と複数駅の統合
- 駅を含む保存と旧版移行

## 対象外

- ホーム、番線、駅舎、駅構内配線
- 一駅への任意の単独停車地点追加UI
- 経路探索、列車走行、需要、運賃

## 完了条件

- [x] 線路上だけに駅を作成できる
- [x] 停車地点が線路ID、線路上距離、位置、方向を持つ
- [x] 線路上の二点で駅範囲を指定し、駅名を専用ダイアログで入力できる
- [x] 開始・終了境界を停車地点へ保存し、線路沿いの範囲を表示する
- [x] 既存駅を同じ線路上の新しい端まで延長できる
- [x] 束内の全線路へ駅範囲を一括設定・延長できる
- [x] 複数駅を選択して一駅へ統合できる
- [x] 駅を選択し、改名・削除できる
- [x] 駅が描画され、保存・復元できる
- [x] 旧version 1〜5セーブを移行できる
- [x] テストと本番ビルドが成功する

## 作業結果
