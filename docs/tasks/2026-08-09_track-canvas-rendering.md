# Task: 線路自体の描画改善

## 目的・背景

線路を太い一本線として描く暫定表示を置き換え、地図倍率に応じて線路記号、左右レール、枕木を判別できるようにする。

## 責任範囲

- 軌間に応じた左右レール描画
- 中心線に沿った枕木描画
- 地図倍率に応じた詳細切替
- 通常、選択、建設中の描き分け
- 複線と曲線への適用
- テスト、ビルド、文書更新

## 対象外

- 軌道支持方式別の外観
- 分岐器と構造物
- 車両描画

## 完了条件

- [x] 中倍率以上で左右レールが見える
- [x] 高倍率で枕木が線路方向に沿って見える
- [x] 低倍率でも線路網を判別できる
- [x] 複線、曲線、選択、建設中表示が維持される
- [x] テストと本番ビルドが成功する

## 検証方法

- `npm run test`
- `npm run build`
- ブラウザで倍率を変え、直線、曲線、複線を確認

## 作業結果

- `0.65`倍未満ではネットワーク確認用の一本線として描画するようにした。
- `0.65`倍以上では軌道下地と左右二本のレールを描画するようにした。
- `1.35`倍以上では線路中心に沿って枕木を描画するようにした。
- レール間隔は線路仕様の軌間をメートルへ変換して使用する。
- 枕木は画面上で潰れないよう、倍率に応じて描画間隔を間引く。
- 選択は赤、建設中は青の状態色を維持した。

## 検証結果

- `npm run test`: 4ファイル、41件成功
- `npm run build`: 成功
- `git diff --check`: エラーなし
- 視覚確認: 利用可能なブラウザがないため人間確認待ち

## 未確認事項・残作業
