# Task: 名前付き複数セーブ

## 目的・背景

一件だけのブラウザ内保存を、名前と日時を持つ複数のセーブスロットへ発展させる。

## 責任範囲

- 名前付きセーブファイル形式
- 複数スロットのブラウザ内保存
- セーブ管理画面
- 新規、上書き、改名、読込、削除、書出
- 旧形式の読込互換
- 自動テストと文書更新

## 対象外

- 自動保存
- クラウド同期
- セーブのサムネイル
- セーブ容量管理

## 完了条件

- [x] 複数の名前付きセーブを作成できる
- [x] 上書き、改名、読込、削除ができる
- [x] 名前と日時を含むJSONを書出・取込できる
- [x] 旧形式を読み込める
- [x] テストと本番ビルドが成功する

## 検証方法

- セーブファイル往復、名前検証、旧形式互換の単体テスト
- `npm run test`
- `npm run build`
- ブラウザで複数スロットを操作

## 作業結果

- セーブ名、作成日時、更新日時、`MapState`を持つセーブファイル形式を追加した。
- 上部の保存・読込を「セーブ管理」画面へ統合した。
- 複数スロットの新規保存、上書き、読込、名前変更、削除、書出を実装した。
- JSON取込時は名前付きスロットへ追加し、その状態を読み込むようにした。
- 旧`MapState` JSONと旧ブラウザ内クイックセーブの移行を実装した。
- セーブ名を1〜80文字へ制限し、書出ファイル名だけ禁止文字を置換するようにした。
