# OSM再取込で欠落した9駅の原因を個別調査

目的: みなみ寄居・寄居等の欠落を元データと実際の判定経路で説明する。
範囲: 元OSM駅・ホーム・線路タグ、診断、事業者判定の反実仮想、ホーム形状の幾何調査。現地データ欠損と実装による除外を区別する。
完了条件: 全9駅の直接原因と、追加の阻害要因を確認し根拠を記録する。
対象外: 推測によるデータ補完・駅の削除・コミット。
関連: [取込器修正](2026-11-08_fix-osm-passenger-platform-matching.md)、[現在仕様](../features/osm-passenger-import.md)。

## 結果・検証

[全9駅の原因](../research/osm-missing-stations-causes.md)。6駅はoperator欠損時の即時return、池袋は値の不一致、西大家はホーム形状が入力に存在しない、武州長瀬は面内部除外等で対応が断片化する。元データ・実判定・診断上の条件変更で確認した。西大家は小範囲の公開OSM API応答も確認した。

ゲーム内で未確定駅を残す実装はなく、セーブ読込も空のstopPointsを拒否することを確認した。調査用の一時コードを削除し、本番コードと地図は変更していない。ゲームテストの再実行は行っていない。修正が必要な構造と駅別の根拠を報告へ記録した。
