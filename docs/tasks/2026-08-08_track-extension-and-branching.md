# Task: 線路の延長操作と途中分岐

## 目的・背景

鉄道線路が折れ線の角で急に曲がらないよう、直線と曲線の敷設操作を役割ごとに分ける。また、既設線路の途中から新しい線路を伸ばせるようにする。

## 責任範囲

- 直線を始点・終点の2点だけで敷設する操作
- 曲線を制御点で滑らかに延長する操作
- 既設線路上の最近点への吸着
- 既設線路の途中から始まる分岐線路
- 接続地点で既設線路の方向を維持する接線拘束
- 吸着位置計算の自動テスト

## 対象外

- 分岐器の設備データと番数
- 線路グラフのトポロジー分割
- 既設線路と同一方向へ滑らかに接続する接線拘束
- 曲線半径と緩和曲線

## 完了条件

- [x] 直線モードでは2点を結ぶ1本の直線だけを敷設する
- [x] 曲線モードでは複数の制御点を使って滑らかに延長する
- [x] 既設線路の途中を始点として新線を敷設できる
- [x] 吸着候補が敷設前に表示される
- [x] 既設線路から伸ばした線路の開始方向が既設線路と一致する
- [x] 自動テストと本番ビルドが成功する

## 検証方法

- `npm run test`
- `npm run build`
- ブラウザで直線、曲線、途中分岐を操作する

## 作業結果

- 直線モードを2クリックで自動確定する操作へ変更した。
- 曲線モードだけが3点以上の制御点を追加できるようにした。
- 直線と曲線の描画サンプルから最近点を計算する吸着処理を追加した。
- 新線の最初の点だけを既設線路へ吸着させ、途中分岐を可能にした。
- 吸着候補を緑色のリングで表示した。
- 吸着線分の接線ベクトルを新線へ保持するようにした。
- 直線の終点を接線軸へ射影し、曲線の開始微分方向を接線へ一致させた。
- 次の制御点の位置から接線の進行方向を自動選択するようにした。

## 検証結果

- `npm run test`: 11件成功
- `npm run build`: 成功
- 線分途中の最近点、吸着距離内外を自動テストで確認
- 直線の軸拘束と曲線開始接線の一致を自動テストで確認
- ブラウザ上の操作感: 人間確認待ち

## 未確認事項・残作業

- 実ブラウザで、既設線路から伸ばす曲線が自然に見えるか確認する。
- 線路グラフ導入時に、吸着位置で既設線路を分割して交点ノードを作る必要がある。

## 引き継ぎ

画面を再読み込みする。既設線路へポインターを近づけ、緑のリングから曲線モードで分岐線を伸ばし、接続点に角が生じないことを確認する。
