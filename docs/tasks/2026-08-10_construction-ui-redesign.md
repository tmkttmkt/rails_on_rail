# Task: 建設モードUI再設計

## 目的・背景

現在の建設UIは「設備を選択」「マップを移動」という性質の異なるツールが、
線路・駅と同列に並んでいて構造が不明瞭。

設計方針に従い、選択をデフォルト状態として、建設ツールは「作るもの」だけに絞る。

設計方針は [Design: 建設モードUI再設計](../designs/construction-ui.md) を参照。

## 責任範囲

- 「設備を選択」ツールボタンの廃止、デフォルト状態として吸収
- 「マップを移動」ツールボタンの廃止
- デフォルト状態でのクリック選択・ドラッグパン動作
- `Escape` / 右クリックで建設ツールを抜けてデフォルトに戻る動作
- 左パネルをツール状態に応じて切替（デフォルト時はツールボタンのみ）
- 右パネルを選択インスペクターとして整理

## 対象外

- 保安装置など将来ツールの実装
- 軌間・レール等の詳細設定折りたたみUI
- 運行モードUIの移動（別Task）

## 完了条件

- [ ] 「設備を選択」「マップを移動」ボタンが存在しない
- [ ] デフォルト状態でクリックすると線路・駅を選択できる
- [ ] デフォルト状態でドラッグするとマップをパンできる
- [ ] `Escape` で線路・駅ツールを抜けてデフォルトに戻る
- [ ] 左パネルがデフォルト時はツールボタンのみ表示
- [ ] `npm run test` 成功
- [ ] `npm run build` 成功

## 検証方法

- `npm run test`
- `npm run build`
- 線路を敷設し、Escapeで抜けて線路をクリック選択できることを確認
- デフォルト状態でドラッグによるパンが動作することを確認
- 駅ツールで駅を設置し、Escapeで抜けて駅をクリック選択できることを確認
