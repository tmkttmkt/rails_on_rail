# Task: UIエリアの役割定義とナビゲーション構造

## 目的・背景

現在のUIは上・左・右の各エリアが担う役割が曖昧で、複数の関心事が混在している。
特に右パネルが選択情報・束操作・運行管理を同居させており、何のためのパネルか分かりにくい。

ゲームがPhase 0以降へ拡張するにあたり、モード概念を導入して各エリアの役割を明確に定義する。

設計方針は [Design: UIエリアの役割定義とナビゲーション構造](../designs/ui-navigation-structure.md) を参照。

## 責任範囲

- 上UIのタブナビゲーション実装（実装済み機能タブのみ有効化）
- モード状態変数の導入と左右パネルのモード別切替
- 右パネルを選択インスペクター（建設モード）に整理
- 未実装タブの無効化表示（グレーアウト）

## 対象外

- 各モードの実際のゲーム機能実装（路線、施設、車両、経営、統計）
- タブ別の詳細UI設計
- レスポンシブ対応

## 完了条件

- [ ] 上UIにタブが表示される（実装済み: 地図・建設・運行 / 無効: 路線・施設・車両・経営・統計）
- [ ] モードによって左パネルの中身が切り替わる
- [ ] 右パネルが選択インスペクターとして機能する（建設モード）
- [ ] 運行操作が左パネルの運行モードへ移動している
- [ ] `npm run test` 成功
- [ ] `npm run build` 成功

## 検証方法

- `npm run test`
- `npm run build`
- 各タブをクリックして左右パネルが切り替わることを確認
- 建設モードで線路・駅を選択してインスペクターが表示されることを確認
- 運行モードで経路作成・列車配置が操作できることを確認
