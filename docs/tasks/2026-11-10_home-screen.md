# ホーム画面を追加する

目的: 起動直後に開始・再開・読込を選べる入口を作る。
範囲: 通常起動のホーム、新規マップ、直近ローカルセーブからの再開、既存セーブ管理による読込、ゲームからホームへの復帰。
対象外: 新しいゲームルール、設定機能、セーブ形式変更、操車UI再編。
判断: 専用map URLは従来通り直接開く。ホーム中はシミュレーションとゲームキーを停止する。進行中のゲームはメモリに保持して戻れる。新規開始で進行中マップを置き換える場合は確認する。ホームの読込から空状態の保存・上書きは許可しない。
完了条件: 初期表示・新規・再開・読込・ホーム復帰が既存機能に接続される。
検証: 全テスト、型検査、ビルド、ブラウザーで主経路を確認。見た目と操作感は人間確認待ちとする。

## 結果・検証

src/main.ts と src/style.css にホームと遷移を実装し、[Feature](../features/home-screen.md)、README、文書索引、Task一覧を更新した。保存形式は変更しない。

34ファイル271テスト成功、型検査・ビルド成功。既存500 kB超バンドル警告あり。差分チェック成功。ブラウザーで保存なし初期表示（続きから無効）、新規開始、時間進行開始後のホーム復帰、ホーム中の日時不変とF2抑止、ロードダイアログの保存・上書き非表示、進行中ゲームへの復帰を確認した。ブラウザーにセーブがないため、保存済みスロットの実読込・最新セーブ再開とファイル取込は今回の手動検証では未実施。撮影はホストのキャプチャタイムアウトで失敗し、外観の画像確認はできていない。

人間確認: 通常URLでホーム外観、新規開始、ゲーム上部からホーム、続きから、既存データのロードを確認する。コミット・プッシュは行わない。
