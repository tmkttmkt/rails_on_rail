# Task: ベカソヴォで貨車の入換を動かす

## 目的

2026-11-03の動機変更と2026-11-07の依頼に従い、ベカソヴォの既存配線上で組成・組み換えを操作できるようにする。旧Phaseの完了消化より本Taskを優先する。旧Phaseは履歴を保持し、新フェーズ体系の確定は別途行う。

## 範囲と完了条件

- 元セーブを保持し、ベカソヴォの配線を使う試験セーブを生成する。
- UI・AI共通命令で線路上の車両列を移動、反転、解結、連結できる。
- 車両長を維持し、分岐を通過中も複数線路上の占有を保持する。
- 経路と占有を検査し、競合時は待つ。貨車単独は動力なしで動かさない。
- 二方面の貨車を仕分ける実行計画を用意し、実マップで最後まで検証する。
- 保存途中から再開できる。型検査・回帰テスト・ビルドを通す。
- ブラウザ確認手順と機械検証結果を残す。人間の操作感確認まではreviewとする。

## 対象外

実ベカソヴォの運転取扱の再現、重力ハンプ、信号連動、制動・牽引力の物理計算、経済需要。今回の車両・速度は試験設定であり実車の再現ではない。
