# Task: 留置場の範囲へ分岐支障を反映する

## 目的と範囲

前回の配置検査だけでは広すぎる留置範囲表示が残る。共通の分岐間隔を使い、既存マップの構内範囲表示とOSM生成範囲を絞る。
施設名と運用参照、保存形式、既存配置は維持する。旅客駅のホーム表示は対象外。

## 設計と完了条件

- サンプル線形の線分に対し必要中心間隔4 m未満の区間を除く。境界は最大0.25 mの保守的な誤差で切る。
- 既存マップでは保存済み範囲と利用可能区間の積集合を描画する。分割された区間も別々に描く。
- インポーターは既存の曲線・最小長条件を維持し、共通判定から得た区間で生成範囲も短縮する。現行モデルの同一線路1停車地点の制約に合わせ、生成時は最長区間を採用する。
- 分岐両側の範囲短縮と区間分割をテストし、全テスト・ビルドを確認する。

## 検証結果

- `npm test`: 26ファイル218テスト成功。`npm run build`: 型検査・本番ビルド成功。
- 既存OSMセーブで算出: ベカソヴォの構内範囲105,373.8 m → 99,407.4 m（127地点変更、15.3 ms）、東上線29,476.2 m → 17,000.2 m（104地点変更、5.3 ms）。保存ファイルは変更していない。
- `git diff --check`: 成功。原データがリポジトリ内にないためOSM再取り込みは未実行。
- 残作業: ブラウザで既存OSMマップを開き、分岐付近の強調が途切れ、施設名と旅客ホームは残ることを人間確認する。
