# Task: N本の線路を同時敷設

## 目的・背景

単線だけでなく、複線や複々線など任意本数の平行線路を一度の線形指定で敷設できるようにする。

## 責任範囲

- 1〜8本の線路本数指定
- 中心線から等間隔に配置した平行線路の描画
- 直線・曲線・プレビューへの適用
- 平行線路ごとの選択・吸着判定

## 対象外

- 上下線の運行方向
- 線路ごとの規格や用途
- 渡り線と分岐器
- 線路間隔のUI変更

## 完了条件

- [x] 1〜8本から敷設本数を選べる
- [x] 指定本数が中心線の左右へ等間隔に描画される
- [x] 直線と曲線の両方へ適用される
- [x] 各平行線へ選択・吸着できる
- [x] 自動テストと本番ビルドが成功する

## 検証方法

- 平行線生成の単体テスト
- `npm run test`
- `npm run build`
- ブラウザで1本、2本、4本、8本の直線と曲線を敷設する

## 作業結果

- 線路群へ本数と線路間隔を保存するモデルを追加した。
- 中央線の接線から法線を求め、N本を左右対称に配置する共通処理を実装した。
- 直線、曲線、敷設中プレビューへ平行線生成を適用した。
- 選択と吸着判定を各平行線の描画形状に適用した。
- 左側ツールへ1〜8本の数値入力と±ボタンを追加した。

## 検証結果

- `npm run test`: 14件成功
- `npm run build`: 成功
- 3本と4本の対称配置を自動テストで確認
- ブラウザ上の操作感: 人間確認待ち

## 未確認事項・残作業

- 急曲線で外側・内側線路の間隔が自然に見えるか確認する。
- 個別線路を別々の運行資産として扱うモデルは未実装。

## 引き継ぎ

画面を再読み込みし、本数を2、4、8へ変更して直線と曲線を敷設する。既設の平行線へ吸着できることも確認する。
