# Task: キーボード割当の一元管理

## 目的・背景

UI文言とイベント処理へ散在するキー割当を一か所へまとめ、今後の接続調整やキー変更で表示と実動作がずれないようにする。

## 責任範囲

- キーアクション、候補キー、表示名、使用場面の定義
- 既存ショートカット判定の共通化
- `kbd`表示の共通定義参照
- 入力欄操作中のゲームショートカット抑止
- 操作一覧文書

## 対象外

- プレイヤーによるキー変更UI
- 設定の永続化
- N/Mによる接続対応調整の本体

## 完了条件

- [x] 既存キー割当が一ファイルに集約される
- [x] 表示と判定が同じ定義を参照する
- [x] 入力中にゲーム操作が発火しない
- [x] 予約割当を文書化する
- [x] テストと本番ビルドが成功する

## 検証方法

- キー一致と入力対象判定の単体テスト
- `npm run test`
- `npm run build`

## 作業結果

- `src/ui/keybindings.ts`へ操作名、候補キー、表示名、使用場面、実装状態を集約した。
- 既存の確定、点を戻す、取消、撤去を共通判定へ切り替えた。
- ボタンの`kbd`表示を同じ定義から生成するようにした。
- 入力欄、選択欄、編集可能要素ではゲームショートカットを抑止した。
- N/M、0、Tabを接続対応調整用として予約した。人間確認により左右移動はN/Mだけを使用し、カンマ／ピリオドは割り当てないことにした。
- `docs/controls.md`へ人間向け一覧を作成した。

## 検証結果

- `npm run test`: 6ファイル、56件成功
- `npm run build`: 成功
- `git diff --check`: エラーなし
- キー候補一致、表示名、入力対象判定を自動テストで確認

## 未確認事項・残作業

- プレイヤーによるキー変更と保存は未実装。
