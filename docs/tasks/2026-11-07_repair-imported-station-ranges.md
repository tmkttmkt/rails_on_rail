# Task: OSM駅範囲の遠隔誤生成を横断修復する

## 目的・範囲

全18保存マップを検査し、ベカソヴォ原版・分割版と東上線で同じ2 m範囲の誤生成を検出した。
Claude履歴に記録された一時フォルダーに元の線路・駅OSMデータが残っていたため、元駅座標から該当停車範囲を復元する。
他の線路・施設・運用は変更しない。自動修復は2 mの既知誤生成に限定し、参照のある停車場は拒否する。

## 判断

軌道点の平均緯度経度から元インポーターと同じ投影を再構成する。同名駅が複数なら、マップ線路までの距離が最小の駅ノードを選び、曖昧な場合は拒否する。
停車位置の投影を含む局所区間を使い、留置用の曲線半径・隣接線との間隔や線路全体の最長区間を旅客ホームへ適用しない。旅客範囲は実際の分岐接続点間で切り、分岐点をまたがせない。境界の0.001 mは数値上の分離であり実物の接触限界を表す値ではない。
既存駅に所属していた線路だけを対象とし、既存の正常範囲は維持する。データから復元できない線路の不正範囲は削除するが、駅を空にはしない。
変更前JSONをバックアップし、保存再読込・再走査・全テスト・ビルドで確認する。目視確認は別途残す。
