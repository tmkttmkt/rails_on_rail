# Task: 曲線生成を円弧チェーンへ置換

## 目的・背景

後から追加した制御点によって既存部分の形と半径が変わるCatmull–Rom方式を廃止し、鉄道線形として操作結果を理解しやすい円弧チェーンへ置き換える。

## 責任範囲

- 開始位置と接線から終点へ至る円弧生成
- 円弧終端方向の次区間への継承
- 確定済み区間が後続点で変形しないこと
- 既設線路からの開始方向維持
- 既設線路への終端接続維持
- 半径計算との統合
- UI説明、自動テスト、現在仕様文書

## 対象外

- 正式な緩和曲線
- 二円弧接続の最適化
- 敷設後編集

## 完了条件

- [x] 通常の曲線区間が一定半径の円弧になる
- [x] 点を追加しても確定済み区間が変形しない
- [x] 円弧同士が接線方向を引き継ぐ
- [x] 既設線路との開始・終端接続が維持される
- [x] テストと本番ビルドが成功する

## 検証方法

- 円弧半径、終端方向、確定区間不変性の単体テスト
- `npm run test`
- `npm run build`
- ブラウザで曲線を連続敷設して操作感を確認

## 作業結果

- 曲線描画をCatmull–Romスプラインから円弧チェーンへ置き換えた。
- 開始接線と終点から一意に決まる円弧を生成し、終端接線を次区間へ引き継ぐようにした。
- 自由な場所から始める場合は最初の2点を直線として初期方向を確定するようにした。
- 既設線路へ接続する最終区間は、両端接線を維持する暫定接続曲線とした。
- UI説明を新しい操作方法へ更新した。
- 人間確認で、途中区間の終点を現在方向の後方へ置くと進行方向が反転する問題が見つかった。方向選択を開始時だけに限定し、以後は前区間の終端方向を反転せず引き継ぐよう修正した。

## 検証結果

- `npm run test`: 4ファイル、41件成功
- `npm run build`: 成功
- 既知の円弧が全点で一定半径になることを自動テストで確認
- 後続点追加後も確定済み区間のサンプル座標が変化しないことを自動テストで確認
- 次の終点が後方にあっても区間境界の進行方向が反転しないことを自動テストで確認
- ブラウザ操作: 利用可能なブラウザがないため人間確認待ち
