# Task: 既設線路間の曲線接続位置をキーで調整する

## 目的・背景

既設線路の束から別の既設線路の束へ曲線を接続するとき、出発側と到着側でどの線路同士を対応させるかを個別に調整できない。両側の束内接続対応を別々のキーで移動可能にする。

## 責任範囲

- `N/M`による出発側の束内接続対応移動
- `,/.`による到着側の束内接続対応移動
- 移動後の位置・接線・半径プレビュー更新
- 終点クリックによる調整後の確定
- キー割当、画面案内、Featureの更新
- 自動テストとChrome実操作確認

## 対象外

- 移動量を変更するUI
- 接続位置のマウスドラッグ
- 自動半径最適化

## 完了条件

- [x] 既設線路間の曲線接続で出発側の束内対応を`N/M`により移動できる
- [x] 到着側の束内対応を`,`/`.`により移動できる
- [x] 移動に応じて接線、線形、半径表示が更新される
- [x] 線路端を越えず、終点クリックで調整後の位置へ確定できる
- [x] 束内対応へ修正後のテストとブラウザ操作を区切りの総合確認で実施する

## 方針・判断

`N/M`は既存どおり出発側の接続対応番号を移動する。`,`/`.`は到着側に独立した接続対応番号を持たせて移動する。到着側は終点へカーソルを合わせている間に調整し、従来どおり終点クリックで接続を確定する。

## 作業結果

- 到着側にも出発側と独立した接続対応番号を追加した。
- 既設線路間の曲線接続は、終点へカーソルを合わせている間に到着側を調整し、終点クリックで確定するようにした。
- `N/M`で出発側、`,`/`.`で到着側の束内接続対応を左右へ移動するようにした。
- 移動後の二円弧、半径表示、接続点を即時更新し、終点クリックで確定するようにした。
- 終点クリック後にさらに`Enter`を要求して接続不能に見えていた回帰を修正した。
- スナップ候補を確定済み終点と誤判定して曲線プレビューが消える回帰を、候補中と確定済みの状態を分離して修正した。
- 複線の終点だけを接続先へ移動して直前に折れが生じていたため、位置補正を線形全体へ滑らかに分散し、両端の接線を保つよう修正した。
- 到着側の対応が束の端を越える場合、未対応線を元位置へ残さず、到着束の間隔を外側へ延長した位置へ並べるようにし、曲線同士の交差を防いだ。
- 接続方向によって到着束の格納順が新設束の左右順と逆になる場合があるため、接続地点で両端の距離を比較し、交差しない向きへ到着束の順序を反転してから描画と接続データを対応付けるようにした。
- 建設中だけ接続位置補正前の線形から最小半径を計算していたため、描画・確定処理と同じ補正済み複線点列を解析するよう統一した。
- 画面案内、キー割当、Feature、操作文書を更新した。

## 検証結果

- 距離方向と誤解した初回実装では`npm run test`が17ファイル、207件成功したが、束内対応へ修正後はユーザー方針に従って全テストを再実行していない。

- 初回ブラウザ確認は要求を距離方向と誤解した実装に対する結果であり、束内対応へ修正後のブラウザ確認は区切りの総合確認へ回す。
