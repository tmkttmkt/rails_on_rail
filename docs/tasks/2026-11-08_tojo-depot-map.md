# OSM東上線の車庫・留置線マップ

依頼: OSMを基準に東武東上線の車庫・留置線をしっかり作った地図を用意する。本体main上のマップ作成であり、試作ハンプは取り込まない。
範囲: 池袋〜寄居と越生線。本線・ホーム・車庫・留置線・出入庫接続を点検し、1067 mm軌間、施設名と有効な留置区間を設定する。OSMスナップショットに無い現地配線の捏造は行わない。
完了条件: 別名セーブ生成、再読込、主要車庫への経路と留置可能長を検証し、ゲーム画面で地図と主要施設を確認する。基準時点・未再現部分・ソースを記録する。
関連: [OSM調査と地図設計](../research/tojo-depot-map.md)。人間の最終的な配線・視認性評価はレビュー待ちとする。

## 成果と検証

- OSM取込の線形を保持し、全線1067 mmへ修正。東上本線と越生線の46駅、11施設、266線路、102留置区間を生成。
- 本線接続成分だけを採用し、元線路点列不変、不正接続ゼロ、全旅客駅存在、分岐支障なし、ホーム範囲重複なし、保存再読込を確認。
- 各留置区間へ駅ホームから有向経路を探索。川越市などは引上げ反転を許して検証。小川町の到達未確認1区間は登録除外。
- 200 m／80 m対応区間数と除外理由をローカル診断レポートへ保存。これは実際の番線数・収容力ではなくゲーム区間長である。
- 専用URL入口と施設移動一覧を追加。Edge `http://localhost:5174/?map=tojo-depots` で森林公園、下板橋の配線・範囲を目視確認。上福岡224 mの留置範囲と全線への移動も確認。
- `npm test`: 238件成功。`npm run build`: 成功。
- 詳細と限界: [Feature](../features/tojo-depot-map.md)。新規OSM取得失敗のため、基準は既存の2026-11-06取込スナップショットである。

未確認: 人間による現地配線との最終照合、200 m編成での全入出庫行程の実走、ダイヤ・信号の運用。コミットは行わない。
