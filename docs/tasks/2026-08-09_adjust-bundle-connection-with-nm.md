# Task: N/Mで線路群の接続対応を調整

## 目的・背景

N本の既設線路群からM本の新線を伸ばす際、中央寄せだけでなく、始点クリック後にN/Mキーで接続する連続線路範囲を左右へ移動できるようにする。

## 責任範囲

- N本とM本から連続する全接続候補を生成
- 中央寄せ候補の初期選択
- 始点クリック後のN/Mによる候補移動
- 候補番号の画面表示
- 敷設プレビューと確定接続への反映
- 自動テストと現在仕様文書

## 対象外

- マウス位置による自動候補変更
- 接続後の対応編集
- 非連続な線路対応

## 完了条件

- [x] Nで左、Mで右の候補へ移動できる
- [x] 候補は範囲端で停止する
- [x] プレビューと確定結果が同じ候補を使う
- [x] N本とM本の大小両方に対応する
- [x] テストと本番ビルドが成功する

## 検証方法

- 候補生成と範囲制限の単体テスト
- `npm run test`
- `npm run build`
- ブラウザで始点クリック後にN/Mを押して確認

## 作業結果

- 最初は少ない側の全線が接続する`|N-M|+1`候補としていたが、一本だけ接続する端の配置へ移動できなかった。
- 最低一本が接続する`N+M-1`個の候補へ修正した。
- 初期候補を一律の中央寄せから、クリックした既設線を起点として束の中央側へ新線を並べる方式へ変更した。
- クリック位置から決めた初期候補を、N/Mで左右へ増減できるようにした。
- 直線モードは既設直線では先端接続だけに限定し、既設曲線の途中からは接線方向へ生やせるようにした。終点は延長軸と方向が一致する先端だけへ接続する。
- 始点吸着後に候補番号、候補総数、N/M操作を工事パネルへ表示した。
- 選択候補に応じて敷設プレビュー全体を対象線路へ整列した。
- `track.create`へ候補番号を渡し、プレビューと同じ個別線路接続を保存した。
