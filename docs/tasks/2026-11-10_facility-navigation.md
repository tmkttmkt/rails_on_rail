# 建設と施設の操作を分離する

目的: 新設・物理変更は建設、駅グループの作成修正と既存施設の管理上の編集は施設へ収める。
範囲: 施設タブの有効化、構内編集の既存パネルへの統合、地図上部の専用入口撤去、名称・用途編集の配置。
対象外: 操車タブの移動、シミュレーションや保存形式の変更、新しい設備工事機能。
完了条件: 地図に専用UIを常設せず、施設タブでグループ・領域を編集できる。駅・側線施設の新設は建設で行う。
検証: 型検査・全テスト・ビルド・差分確認。人間確認は施設タブで川越市の領域を選択し、建設への切替と新設操作を確認する。

## 結果

施設タブを有効化。構内グループ・領域編集を既存左パネルへ統合し、地図上部の専用ボタンを撤去。右パネルで既存駅名・側線用途を編集する。領域に属する停車場は領域編集を使い、二重の用途・名称編集を表示しない。新設・拡張・統合・撤去は建設に残し、施設モードのDeleteによる物理撤去も防ぐ。グループ名変更UIを追加した。

変更: src/main.ts、src/ui/stationComplexPanel.ts、src/ui/facilityPanel.ts、src/style.css、対応Feature・Design・Task一覧。保存形式と配線は変更しない。操車タブと往復試験のロジックは変更せず、試験操作は建設の右パネルに残した。

検証: 最終コードで34ファイル271テスト成功、型検査とビルド成功、git diff --check成功。通常サンドボックスのEPERMは権限制限外の再実行で解消。既存500 kB超のバンドル警告あり。browser-useで /?map=tojo-areas の読込、地図で専用編集UI非表示、施設タブのグループ7領域表示と領域選択、建設で新設ツール表示、施設への再切替をアクセシビリティ情報で確認。旧初期化が固定パネルを削除する不具合を画面確認で発見し修正した。スクリーンショットは取得タイムアウトのため未取得。見た目・操作感の人間による受入と新設・保存の手動確認は未実施。
