# Task: AI連携用APIのVite開発サーバー組み込み

## 目的
人間のプレイ中にAI（Antigravity/agyなど）へ指示を出し、AIがゲームを直接操作できる「AIアシスタント機能」の土台を構築する。
メイン機能の実装（CodexやClaudeが担当）に影響を与えないよう、Vite開発サーバーの拡張機能としてAPIを追加し、ブラウザのポーリングでコマンドを受け取る形式とする。
本Taskの設計と実装はagy（Antigravity）が担当する。
本Taskに関連する設計と、AI側で必要になる軌道機能については [Design: AI連携用APIのVite開発サーバー組み込み](../designs/2026-08-10_ai-api-integration.md) を参照。

## 実装するAPIの範囲
複雑なサーバー実装は避け、最低限のやり取りを行うため以下の2つのエンドポイント（インメモリのキュー）のみを作成します。

1. **状態同期 API (`/api/state`)**
   - `POST`: ゲーム（ブラウザ）側から最新のゲーム状態（JSON）を送信し、サーバーのメモリ上に保持する。
   - `GET`: AI（agy）がサーバーから現在のゲーム状態を取得する。
2. **コマンドキュー API (`/api/commands`)**
   - `POST`: AI（agy）がゲームに実行させたいコマンド（`MapCommand[]`）をJSONで送信し、サーバーのキューに追加する。
   - `GET`: ゲーム（ブラウザ）側が定期的にアクセスし、未実行のコマンドを取り出してブラウザ上で実行する（取得後はキューを空にする）。

## 完了条件
- [x] `vite.config.ts` を作成し、カスタムViteプラグインで上記APIを実装する。
- [x] `src/main.ts` または該当箇所に、定期的にAPIと通信して状態の同期とコマンドの実行を行う処理を追加する。
- [x] 外部（AI）からコマンドを送信し、実行中のゲーム画面に即座に反映されることを確認する。
