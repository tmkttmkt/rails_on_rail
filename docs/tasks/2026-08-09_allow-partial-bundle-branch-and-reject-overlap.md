# Task: 一本以上の接続で束分岐を許可し重ねがけを拒否

## 目的・背景

N本からM本への分岐で全線対応を要求せず、一部線路だけが接続する束を建設可能にする。一方、既設線と同じ区間へ新線を重ねる無意味な建設を拒否する。

## 責任範囲

- 一本以上の個別接続による束分岐
- 未対応線路を残した新線束
- 中心線区間の重複検出
- 点接触と交差の許可
- 自動テストと現在仕様文書

## 対象外

- 三線軌条とガントレット軌道
- 近接並走の安全離隔
- 立体交差の高さ判定

## 完了条件

- [x] 束の一本以上が接続すれば分岐できる
- [x] 余った新線を未接続で保持できる
- [x] 同一区間への重ねがけを拒否する
- [x] 点接触と交差を拒否しない
- [x] テストと本番ビルドが成功する

## 検証方法

- 一部接続、完全重複、交差の単体テスト
- `npm run test`
- `npm run build`

## 作業結果

- 新線束のうち最低一本が既設束と個別接続すれば分岐を作成できるようにした。
- 接続候補を`N+M-1`個生成し、N/Mで一本だけ接続する端の配置まで選べるようにした。
- N/M候補で対応しなかった新線は未接続線として束内に保持するようにした。
- 二つの中心線について、同一直線上の線分が有限長重なる量を計算する処理を追加した。
- 新線と既設線の重複長が存在する場合、`track.create`を拒否するようにした。
- 端点共有と一点交差は重複長ゼロとして許可した。

## 検証結果

- `npm run test`: 6ファイル、64件成功
- `npm run build`: 成功
- `git diff --check`: エラーなし
- 3本束のうち一本だけへ接続する分岐、完全重複の拒否、一点交差の許可を自動テストで確認
- ブラウザ操作: 利用可能なブラウザがないため人間確認待ち

## 未確認事項・残作業

- 実画面で一本だけ接続する束分岐と重複時のエラー表示を確認する。
- 三線軌条、ガントレット軌道、立体交差は専用データ・形状が必要なため未実装。

## レビュー修正

- 人間確認で、既設線と同じ接線から始まる緩い分岐が重ねがけとして拒否される問題が見つかった。
- 重複判定の許容値を完全一致に近い値へ縮小し、比較する線分の始点だけでなく終点も同一直線上にある場合だけ重複として数えるよう修正した。
