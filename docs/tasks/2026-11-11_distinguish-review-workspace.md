# 本番との差分に合った検証用UIを整える

目的: 検証内容と本番との差分に合った操作UIを整える。

範囲: 地図上部の「東上線｜近似再現（番線・短編成は仮設定）」などの専用補助ナビゲーションだけを検証用と分かる表示にする。

対象外: シミュレーション、保存形式、通常UIの作り直し、新しい試験シナリオ。

設計: 対象部分にだけ「検証用UI」の小ラベル、薄い黄土色の背景、破線の枠を付ける。画面全体への帯・テーマ変更や新しい操作パネルは追加しない。既存のタイトルと移動選択は維持する。

完了条件: 確認した意図に基づく具体的な操作UIと、関連文書・検証結果が揃う。

実装: `src/main.ts` の専用マップ補助ナビゲーションへラベルと地域ラベルを追加し、`src/style.css` に局所的な外観を定義した。専用入口でこのナビゲーションが生成された場合だけ表示する。通常のゲーム操作UIは変更しない。表示の読みやすさは `/?map=tojo-trial` で人間確認待ち。

検証: 型検査・ビルド、既存テスト、差分と文書リンク。外観と操作感は人間確認待ち。

検証結果: `npm run build` の型検査は成功したが、既存distの削除権限でビルドが失敗した。`node node_modules/vite/bin/vite.js build --outDir node_modules/.review-ui-build` は成功。既存の500kB超バンドル警告あり。`git diff --check` 成功。見た目とラベルのみの変更のためテストは追加・再実行していない。ブラウザーでの外観確認は未実施。

関連: [ホーム](../features/home-screen.md)、[短編成試験](../features/tojo-playable-trial.md)。

引き継ぎ: ユーザーの追加依頼により、他の検証用UIにも適用する[表示規約](../review-ui.md)をoperation文書として追加し、AI命令書・文書索引・開発ワークフローから参照させた。適用範囲、ラベル・背景・枠、既存CSSの再利用方法、地図用レイアウトを他パネルへ流用しないことを記録した。この追記は文書のみであり、他パネルへの一括適用は実施していない。
