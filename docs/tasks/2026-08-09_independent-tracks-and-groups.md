# Task: 個別線路を実体にして線路群を再編可能にする

## 目的・背景

線路群を本体として仮想的な個別線路を生成する構造を廃止し、独立線路を本体、線路群を変更可能な束へ変更する。

## 責任範囲

- 個別`Track`と`TrackGroup`のゲーム状態
- 同時敷設時の独立線路生成と自動グループ化
- 束作成、追加、除外、解体
- 複数選択UI
- 線路撤去時の束更新
- version 1セーブからversion 2への移行
- 自動テストと現在仕様文書

## 対象外

- 線路群の用途・運行方向
- 線路順序の手動入替
- 離隔・平行性の警告
- 渡り線と分岐器

## 完了条件

- [x] 一本ごとの線形・仕様・工学状態を保存する
- [x] 同時敷設した複線を独立線路として自動的に束ねる
- [x] 複数選択から束を作成できる
- [x] 線路の追加、除外、束解体ができる
- [x] 旧セーブを移行できる
- [x] テストと本番ビルドが成功する

## 検証方法

- 線路生成、束操作、撤去、旧セーブ移行の単体テスト
- `npm run test`
- `npm run build`
- ブラウザで複数選択と束操作を確認

## 作業結果

- `Track`を一本の物理線路へ変更し、完成線形、仕様、工学状態、接続を個別保持するようにした。
- `TrackGroup`を追加し、二本以上の線路IDを順序付きで参照する束とした。
- 同時敷設ではN本の独立線路を作り、二本以上なら自動的に束を作るようにした。
- 個別線路同士を中央寄せで対応づけて接続するようにした。
- Shift＋クリックの複数選択と、束作成、追加、除外、解体UIを追加した。
- 線路撤去時に束から除外し、残り一本以下なら束を自動解体するようにした。
- ゲーム状態をversion 2へ更新し、version 1の線路群を独立線路と束へ展開する移行を追加した。

## 検証結果

- `npm run test`: 5ファイル、53件成功
- `npm run build`: 成功
- `git diff --check`: エラーなし
- 同時敷設、個別接続、束作成、除外、自動解体、明示解体、旧セーブ移行を自動テストで確認
- ブラウザ操作: 利用可能なブラウザがないため人間確認待ち

## 未確認事項・残作業

- 実画面でShift＋クリックによる複数選択と各束操作を確認する。
- 線路順序の手動変更、用途、運行方向、離隔警告は後続Taskとする。
