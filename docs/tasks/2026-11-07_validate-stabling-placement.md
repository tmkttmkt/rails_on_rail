# Task: 編成全体の留置範囲と分岐支障を検査する

## 目的・責任範囲

共通の `fleet.formation.place` で編成全体の範囲包含と分岐付近の留置禁止を強制する。
関連: [運転上の区分](2026-11-06_introduce-operational-classification.md)、[Phase -1](../epics/phase-minus-one.md)。

## 設計判断

- 既存の停車範囲を今回の許可範囲として利用し、施設モデルと保存形式は変更しない。
- 分岐接続点をまたぐ留置を拒否する。単なる端点間の継目は対象外。
- 分岐に参加する別線路と、配置編成が占める線路区間との最短距離を検査する。
- 必要中心間隔はデータに置く暫定ゲーム値4 m。軌間から車両幅を推定しない。実際の規格適合を保証する値ではない。
- 距離検査は既存のサンプル線形上で行う。近接する分岐線全体を対象とする保守的な判定である。
- 施設のグループ化、全線路間の車両干渉、走行中の進路制御、既存配置の再検証、取り込み閾値の撤去、表示変更は対象外。

## 完了条件・検証

- 編成の両端が停車範囲を越える配置を拒否し、境界に収まる配置を許可する。
- 基準線・分岐線の両方で接続点付近への配置を拒否し、十分離れた位置を許可する。
- 継目の回帰確認、全テスト、型検査とビルド、既存再現スクリプトを実行する。
