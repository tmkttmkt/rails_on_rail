# Task: 複数線路間の個別接続

## 目的・背景

線路群を見た目だけの平行線ではなく、個別に識別・接続可能な線路の集合として扱い、複線から複線を正しく伸ばせるようにする。

## 責任範囲

- 線路群内の個別線路ID
- 既設線路群中央線への吸着
- 新旧線路群の個別線路対応
- 本数が異なる場合の中央寄せ対応
- 始点・終点接続情報の保持と表示

## 対象外

- 対応関係を人間が編集するUI
- 渡り線と分岐器の具体形状
- 線路グラフによる経路探索
- 既設線路側への双方向接続情報の書き戻し

## 完了条件

- [x] 線路群内の各線路が安定したIDを持つ
- [x] 複線へ吸着した新しい複線の中心線と各線が整列する
- [x] 新旧線路群の個別線路対応が保存される
- [x] 本数が異なる場合は中央基準で接続可能な線路だけ対応する
- [x] 接続本数を選択情報で確認できる
- [x] 自動テストと本番ビルドが成功する

## 作業結果

- 線路群内へ安定した個別線路IDを生成するようにした。
- 始点・終点接続へ、接続先線路群IDと個別線路IDの対応を保存するようにした。
- 個別線路をクリックしても、新線の中心線は接続先線路群の中心線へ吸着するようにした。
- 同本数は位置番号同士、異なる本数は中央寄せで対応づける処理を追加した。
- 選択情報へ線路群の本数と接続済み個別線路数を表示した。

## 検証結果

- `npm run test`: 17件成功
- `npm run build`: 成功
- 個別線路ID、4本→2本の中央対応、2本→2本の接続保存を自動テストで確認
