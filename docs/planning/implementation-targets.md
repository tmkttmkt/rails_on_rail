# 実装対象の順序

2026-11-10に決めた開発方針。これは完成時期や機能を一括固定するロードマップではなく、当面の実装対象を示す。

## 最初の目標：MVP（東武東上線の部分的再現）

- 実在する東武東上線の一部を題材に、遊べる最小構成を作る。
- 再現する区間、再現の粒度、具体的な完成条件はまだ決定していない。決定済みであるかのように扱わない。
- 既存の[東上線・越生線の車庫／留置線マップ](../features/tojo-depot-map.md)は活用候補であり、既にMVPが完成したことを意味しない。
- 直通、ダイヤ、車庫、運用などの必要性は、MVPで実際に再現する範囲に応じて決める。最初から全機能を必須とはしない。

## 次の実装対象：ベガソボロ操車場

- 貨車の流動、入換、仕分、編成の組成・解結、出発、大規模操車場の運用を扱う。
- 既存資料では「ベカソヴォ」と表記されている。同じ操車場を指す。
- 先行した[操車場実働化の試作と記録](../epics/yard-operations.md)は保持するが、当面の新規実装の優先対象は東上線MVPである。
- 操車場の全機能をMVPの完成条件へ含めない。

## 管理方針

- 「Phase -1〜6」のようなフェーズ分割は採用しない。
- 実装対象と、それに必要な機能・課題を個別に扱う。EpicやTaskを使う場合もフェーズへの所属は要求しない。
- 規格・経営・鉄道史・AIによる操作などの長期構想を撤回したわけではない。MVPの必須機能にも自動的にはしない。
- 方針とコードの管理先はこのGitHubリポジトリとする。この開発方針をNotionへ二重記録しない。
