# 開発段階

Rails on Rail は、最初から全機能を実装せず、ゲームとして成立する最小単位から段階的に発展させる。

## Phase -1: 技術プロトタイプ

本格的な実装前に、駅と線路の編集、経路探索、列車移動、保存と読み込みを最小構成で検証する。

この段階では、ゲームとしての完成度よりも、シミュレーションと表示の分離や、人間とAIが共通の操作命令を利用できる構造の確認を優先する。

現在の詳細は [`../epics/phase-minus-one.md`](../epics/phase-minus-one.md) を参照する。

## Phase 0: 鉄道が動く

最初の技術検証段階。

- 2D地図表示
- 線路敷設
- 駅設置
- 列車配置
- 経路探索
- 列車移動
- 最低限の保存と読み込み

この段階では経営や鉄道工学を深く再現しない。

## Phase 1: 鉄道経営の核

最初のゲームとして成立する段階。

- 路線
- 駅間需要
- 運行本数
- 運賃または輸送収益
- 建設費
- 維持費
- 赤字路線
- レール規格
- 車両の重量・軸重・速度
- 路線休止
- 廃止
- 線路撤去

車両とインフラ規格の違いによる制約を、この段階から導入する。

## Phase 2: 運行

鉄道網の運行そのものを拡張する。

- ダイヤ
- 複線・単線
- 待避
- 追越し
- 閉塞
- 信号
- 車庫
- 編成
- 輸送力
- 混雑
- 遅延

## Phase 3: 鉄道工学

インフラをより細かく扱う。

- レール
- 枕木
- 路盤
- 橋梁
- トンネル
- 曲線
- 勾配
- 電化
- 信号方式
- 保安装置
- 設備老朽化
- 保線
- 速度制限

## Phase 4: 鉄道会社

会社運営を拡張する。

- 資金調達
- 借入
- 車両購入
- 車両開発
- 更新
- 廃車
- 保守費
- 部門
- 人員
- 貨物契約
- 投資計画

## Phase 5: 社会と制度

鉄道会社の外部環境を導入する。

- 自治体
- 補助金
- 国有化
- 民営化
- 第三セクター
- 土地
- 都市開発
- 道路交通との競争
- 廃線協議
- 災害
- 法制度

## Phase 6: 鉄道史

長期間の歴史シミュレーションとして完成させる。

- 年代
- 技術研究
- 技術普及
- 蒸気機関
- 電化
- ディーゼル化
- 高速鉄道
- 大量輸送
- モータリゼーション
- 地方路線衰退
- 時代ごとの経済・社会変化

最終的には、過去の設備投資や規格選択が数十年後まで影響を残すゲームを目指す。
