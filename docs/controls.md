# 操作とキーボード割当

コード上の正本は[`src/ui/keybindings.ts`](../src/ui/keybindings.ts)である。キーを変更する場合は、イベント処理や画面文言へ直接埋め込まず、この定義を更新する。

## 現在使用中

| 場面 | 操作 | キー |
|---|---|---|
| 線路敷設 | 敷設を確定 | `Enter` |
| 線路敷設 | 最後の点を戻す | `Backspace` |
| 線路敷設 | 敷設を取り消す | `Escape` |
| 線路選択 | 選択線路を撤去 | `Delete` |
| 線路選択 | 複数選択 | `Shift`＋クリック |
| ゲーム全体 | 時間の再生・一時停止 | `Space` |
| 接続対応調整 | 接続候補を左へ移動 | `N` |
| 接続対応調整 | 接続候補を右へ移動 | `M` |

## 接続対応調整用に予約

| 操作 | キー |
|---|---|
| 中央寄せへ戻す | `0` |
| 次の候補へ移動 | `Tab` |

`0`と`Tab`は定義済みだが、現在は動作しない。

入力欄、選択欄、セーブ名の編集中はゲーム用ショートカットを発火させない。
