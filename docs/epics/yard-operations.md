# Epic: ベカソヴォの操車場を動かす

## 現在の位置づけ（2026-11-10）

[実装対象の順序](../planning/implementation-targets.md)により、最初の目標は東武東上線の部分的再現（MVP）、本Epicはその次の実装対象となった。既存の試作・検証・Taskは破棄しない。現在はMVPの完成条件には含めず、再着手時に引き継ぐ。

## 動機

2026-11-03のユーザー発言では、開発再開の動機は「貨物などの組成組み換え」「ハンプ付きの大規模操車場を意味を持って作れるゲーム」である。2026-11-07にベカソヴォの実働を優先し、実装まで進める依頼を受けた。

従来の段階別計画は採用終了となった。歴史・規格・経営の廃止は決めていない。

## 実装・検証したい能力

1. 既存ベカソヴォ上で、線路位置と車両長を保持して牽引・推進・連結・解結できる。
2. 行先別に貨車を仕分け、組成して出発できる。
3. 外部からの継続的な到着、計画編集、複数機関車の作業と滞留を扱う。
4. ハンプと通常入換を比較し、配線・設備によって処理能力が変わる。

## 配下Taskと受入

- [ベカソヴォで貨車の入換を動かす](../tasks/2026-11-07_operate-bekasovo-yard.md): 入換・仕分の試験実装。試験車両7両、既存配線、二方面。
- 継続的な到着やハンプ設備の処理能力比較などは未実装。経済・需要・fleet統合は後続設計の対象。
- 人間による画面の視認性、入換操作感、仕分計画の評価は未確認。

本Epicは一回の仕分試験だけでは完了としない。ハンプを含む処理能力の判断までが目標である。

## 2026-11-08の採用判断

[基盤と試作の分離](../tasks/2026-11-08_split-yard-prototype.md)により、本体はfleet共通化と範囲・接続の基盤を採用する。ハンプ・簡易連動・大規模シナリオ・26施設整形は `prototype/bekasovo-yard` に保留する。本体では小さい問題から積み直す。試作の完走をゲーム仕様の確定と扱わない。
